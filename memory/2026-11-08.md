### 根因（最终锁定，实测）
**运营商在本机上游做 SNI 拦截，不是 IP 段封锁。**
```
同一 IP 104.16.132.229，只改 SNI：
  cloudflare.com → 301 connect=0.178 appconnect=0.366  ← TLS 建起来了
  www.baidu.com  → 403 connect=1.184 appconnect=1.379  ← 同上
  github.com     → 000 connect=0.193 appconnect=0.000  ← TLS 被掐
  chatgpt.com    → 000 connect=0.184 appconnect=0.000  ← TLS 被掐
```
→ **TCP 通、TLS 能建，被拦的是「SNI 里出现特定域名」**
→ 钱怎么花改变：买 VPS 不必挑段，但必须配 Reality/伪装域名/非443端口
→ 双线路验证（en0 有线 / en1 Wi-Fi 不同网段网关）结果一致到小数点后两位 → 运营商级策略
