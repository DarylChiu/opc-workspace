## 教训
- 版权音乐视频（如 Rick Astley）下载音频遇 403 Forbidden（YouTube 版权保护），测试素材应选 TED/教育类非版权视频
- yt-dlp `--sub-langs en.*` 会匹配到 en-ja 等变体触发 429，应精确用 `en`
- **B站 view/playurl API 对这台机器 IP 412 风控**（返回 HTML 非 JSON），`requests.json()` 裸调用会抛 JSONDecodeError；应改用 you-get 下载视频+Whisper转写，且所有第三方 API 调用都要容错
- **开发测试必须覆盖所有平台路径**（YouTube + B站），不能只测 YouTube 就交付——本次 B站路径漏测导致 Daryl 验收时才发现 412 问题
- **抖音反爬强**：旧下载器易失效；抖音音视频分离（media-audio-und-mp4a 独立音频流），Playwright 拦截音频流可绕开视频流/msToken；yt-dlp 抖音需 msToken（JS 生成的风控参数，普通 cookie 不够）
