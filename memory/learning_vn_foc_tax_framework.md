# Learning: 越南 FOC/VAT 税法框架 — 禁止套用中国「视同销售」概念

> 来源：2026-10-07 Self 纠正（Daryl 09:04 已点过同一错误）。这是主线 Agent 向 Daryl 汇报时的术语红线。

## 教训
- **越南法上不存在「视同销售（deemed sale）」制度**，这是中国概念。把中国税法框架投射到越南法是错的，会连累整个团队在错框架里。
- 同样**不存在「VAS 15」**：越南会计准则是 VAS 01–26 体系；会计制度 TT 200/2014 → **现为 TT 99/2025**（2026-01-01 生效）。TT 219/2013 是**旧的增值税指导通知**（非会计准则），已被 Luật 48/2024 ＋ NĐ 181/2025 体系取代。

## 正确框架：越南 FOC（免费赠货）三层分离
| 层 | 规则 | 依据 |
|----|------|------|
| **VAT 层** | 计税价规则（非视同销售）：用于 cho/biếu/tặng 的货物按**同类/等价商品计税价**计缴销项 | Luật 48/2024 Điều 7 |
| **会计层** | **不确认收入**（không ghi nhận doanh thu），全额进 641/642 | VAS / TT 99/2025 |
| **CIT 层** | **不确认应税收入**，只判费用可扣除性 | — |

## 两个高频考点（Daryl 实测用）
1. **开电子发票是否需申报**：是。开票所属期申报进 01/GTGT 销项；纳税义务时点＝交付时点（非收款）；电子发票实时上传自动比对。
2. **赠送采购原料的进项 VAT**：
   - **进项可抵扣** —— Luật 48/2024/QH15 · Điều 14 khoản 7：用于 cho, biếu, tặng, khuyến mại, quảng cáo 的货物（含外购+自产）进项予以抵扣；
   - **退税不行** —— 退税限 Điều 13（0% 出口经营 ＋ 未抵进项 ≥ 300,000,000 VND），FOC 无 0% 出口资格 → 无退税。
   - **申报表行次**：不填 0% 行，填该货物适用税率行（如 8%），依据 CV 90157/CT-TTHT。补税是主项、罚款是附加。

## 关键法条索引
- Luật 48/2024/QH15 — 增值税法（现行）
- NĐ 181/2025 — 配套法令
- TT 99/2025 — 会计制度（2026-01-01 生效，取代 TT 200/2014）
- TT 219/2013 — 旧增值税指导通知（已取代，勿引用为会计准则）
- CV 90157/CT-TTHT — 税局公文（税率行次）
