## 08:05 素材时长全为0 BUG修复 — 与看护脚本同源 ⚠️
- **Daryl 反馈**: 素材扫描出来 4 个视频（2026-05-07 的 185-188）时长都是 0s，导致 ASR 场景识别也错误
- **根因（再次是 launchd PATH）**: 视频编辑器服务由 LaunchAgent `ai.openclaw.videoeditor` 托管，环境 PATH 极简（/usr/bin:/bin:/usr/sbin:/sbin），找不到 /opt/homebrew/bin 的 ffprobe/ffmpeg → scan/asr 里所有 subprocess 调用 FileNotFoundError 被 except 吞掉 → duration 返回 0（orientation 也全默认 16:9，缩略图为空）
- **证据**: 直接跑 ffprobe 正常（73.0/30.7/22.3/11.9s）；ps eww 查服务进程 PATH 确认极简；env -i PATH=... which ffprobe → 找不到
- **修复（双保险）**:
  1. server.py 导入前把 /opt/homebrew/bin、/usr/local/bin 补进 os.environ['PATH']（覆盖全部 api 模块）
  2. api/scan.py + api/asr.py：ffprobe/ffmpeg 改为 shutil.which 绝对路径；get_duration 增加流级 duration + nb_frames/avg_frame_rate 兜底
  3. LaunchAgent plist 加 EnvironmentVariables PATH=/opt/homebrew/bin:... → bootout/bootstrap 重启
- **验证**: 203 个素材 duration_zero=0；4 个问题文件 73.0/30.7/22.3/11.9s ✅；缩略图 API 正常；已提交 55b6b2c
- **教训**: 凡 launchd 托管的服务进程（不止脚本），默认 PATH 都极简；服务代码里不能依赖 PATH 找 Homebrew 工具，要么绝对路径要么启动时补 PATH
