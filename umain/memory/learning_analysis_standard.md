## 团队标准 5 条（强制）

1. **分析至少挖两层** — 现象 → 结构/模式 → 含义
   - 表层结论禁止直接交付，必须穿透到结构层和含义层
2. **先定义口径，结论可被质疑** — 分析前明确指标定义/边界，结论附带可复核依据
3. **找模式不找数据** — 数据是证据，模式才是结论；禁止罗列数据冒充分析
4. **给可执行含义** — 每个分析必须落到「所以该怎么做」，否则不算完成
5. **不确定标注不迎合** — 不确定就明说，禁止为了交付而编造确定感

## 适用范围
- 所有分析类任务（调研、对比、评估、复盘、周报结论）
- **OPC 周报/看板类分析同样适用**：看板上的阶段判断、进度百分比、风险结论必须满足上述标准

## 反例（来自 Self 的 correction 记录）
- 指令频率调查第一轮只看频率被点名表面
- 第二轮加难度结构 + 长线占比才过关
→ 教训：浅层 = 只报现象；过关 = 现象 + 结构 + 含义 + 行动
