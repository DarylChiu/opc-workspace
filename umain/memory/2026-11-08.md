**→ 换干净 DNS 这条路被封死，DoH 方案作废。**

### 二、最终结论

**故障是三层叠加，不是单一原因：**
1. **DNS 污染/劫持**（拿假 IP，含指向国内 IP 的劫持）
2. **DoH 被封**（无法通过加密 DNS 拿真 IP）
3. **真 IP 上 TLS 按 SNI 白名单拦截**（拿到真 IP 也连不上）

**IP × SNI 正交矩阵（16 格实测）：**
```
IP \ SNI          cloudflare.com   www.baidu.com   aliyun.com   github.com
CF 104.16.132.229    301/TLS活        403/TLS活       000/TLS死    000/TLS死
HK 47.242.89.235     000/TLS死        000/TLS死       000/TLS死    000/TLS死
GitHub 140.82.121.4  000/TLS死        000/TLS死       000/TLS死    ✅200/TLS活
```
**规律：SNI 必须和该 IP 实际承载的域名一致才放行。伪装 SNI 反而死。**
