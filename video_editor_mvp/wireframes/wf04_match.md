## 交互清单

| # | 交互 | 默认行为 |
|---|------|---------|
| ①-⑤ | 槽位操作 | 每个槽位: 点击播放预览 / 替换 / 移除；显示 情绪匹配度+节拍对齐度（自动匹配的依据可视化） |
| ⑥ | 点击放入 | 候选池点片段 → 放入第一个空槽位（简单，移动端友好） |
| ⑦ | 拖拽指定 | 拖到指定槽位替换（桌面增强，无则先做⑥） |
| ⑧ | 撤销 | 撤销上一步操作（至少 10 步历史） |
| ⑨ | 重新匹配 | 一键重跑自动匹配（保留手动改过的槽位？→ 默认保留，可勾选"全部重排"） |
| ⑩ | 锁定 | 锁定时间线 → 生成预览（720p，进度条） |
| — | 预览 | 视频播放器 + 时间线联动（播放到哪高亮到哪）→ 🔴决策: [✓通过][✏️调整][↺重来] |

## 决策点（全流程唯一正式决策点）
- **预览 → 通过 / 调整 / 重来**：通过→进入导出；调整→回到素材轨编辑；重来→全部重排
- 「调整」必须有具体抓手: 换片段 / 换槽位 / 拖边界微调切点（±1s 精度）

## 默认值（无需再问）
- 自动匹配策略: 情绪兼容 60% + 节拍对齐 30% + 时长适配 10% 加权（可调权重）
- 手动干预 > 自动结果（手动改过的槽位，自动匹配不再覆盖）
- 导出: 16:9/9:16 × full/30s/15s + SRT（沿用 Phase0 输出管线）

## 前5分钟操作走查
1. 打开匹配页 → 看到 BGM 轨 + 素材轨已自动填好（带匹配度）
2. 点预览 → 播放 → 觉得 Climax 段不够炸
3. 从候选池拖「日落」替换 slot4 → 再预览
4. 撤销 → 恢复 → 锁定 → 导出 360p 预览
5. 通过 → 导出 1080p 成片
