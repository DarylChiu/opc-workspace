## 交互清单（编号对应上图）

| # | 交互 | 默认行为 |
|---|------|---------|
| ① | 素材勾选 | 沿用素材扫描页的勾选状态（步骤间共享，不再各自为政） |
| ② | 视频预览 | 点击播放该素材（复用扫描页生成的预览缓存） |
| ③ | 重新检测 | 单素材重跑，不阻塞其他素材（今天修的"只检测3个"就是反面教材） |
| ④ | 跳过 | 标记跳过，不进入情感/匹配 |
| ⑤ | 进度/状态 | 每素材独立状态: ⏳检测中(带进度) / ✅N场景 / ⚠️失败(可重试) |
| ⑥ | 场景边界 | 时间轴条上拖拽边界；支持 合并相邻/拆分（右键或双击） |
| ⑦ | 描述编辑 | 场景描述文本框直接改 |
| ⑧ | 情绪标签 | 标签 chips 可增删（默认给出候选: 平静/愉悦/震撼/漫步/自由/好奇/生机/叙述/期待/收束） |
| ⑨ | 单素材确认 | 确认后锁定该素材结果，进入下一素材 |

## 决策点
- **每素材「确认」= 人工决策点**（对应流程图的 🔴预览决策，前移到每素材粒度）
- 全部确认后 → 结果汇总 → 进入情感分析模块

## 默认值（无需再问）
- 无对白素材: 自动跳过 ASR 只做场景检测（现状保留）
- 场景数上限: 默认每素材 ≤12 个（Gemini 返回过多时按置信度截断，可调）
- 失败处理: 单素材重试，不阻塞批量

## 前5分钟操作走查
1. 打开 ASR 页 → 素材列表带缩略图+时长+勾选状态（不是干巴巴的卡片）
2. 取消勾选 1 个 → 点「开始检测」→ 只跑 3 个
3. 第一个完成后 → 点开场景时间轴 → 拖一下边界
4. 改一个场景描述 + 删一个情绪标签
5. 确认本素材 → 下一个自动展开 → 全部确认后进入情感页
