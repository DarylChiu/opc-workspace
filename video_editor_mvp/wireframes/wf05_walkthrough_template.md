# 05 · 「前5分钟操作」走查模板

> 用途: 每个模块开发完成、提测前，用 Daryl 的视角走查一遍
> 原则: 不是技术 e2e（能不能跑），是产品走查（好不好用）——两个都过才算完

---

## 模板（每模块一份，提测前自答）

### 1. 首屏直觉
- [ ] 打开页面 3 秒内，不用读文档就知道这是什么、下一步点哪里？
- [ ] 有没有「空状态」？没数据时页面友好吗（不是报错/白屏）？

### 2. 核心操作流（模拟 Daryl 真实操作）
- [ ] 第一步操作是什么？3 次点击内能不能到达核心功能？
- [ ] 每一步操作有没有即时反馈（loading/进度/结果）？
- [ ] 出错时（网络/API/文件损坏）提示是否可理解、可重试、不丢失已做操作？

### 3. 数据可信度
- [ ] 数字、时长、置信度、标签和真实数据一致？（今天「时长0s」「只检测3个」就是这类没走查出来的）
- [ ] 空数据/异常数据（无对白、竖拍、0时长）有合理表现？

### 4. 打断与恢复
- [ ] 长任务中途刷新页面，状态还在吗？（本地缓存）
- [ ] 误操作能撤销吗？（删除/覆盖/替换至少一步可回退）

### 5. 移动端/最小窗口
- [ ] 缩到手机宽度还能操作吗？（Daryl 常用手机看）

### 6. 对照承诺
- [ ] 这个模块的设计稿/需求逐条打勾了吗？（线框里的每个交互编号都要有实现）

---

## 走查结果记录格式

```
模块: XX
日期: 
走查人: Bryson（提测前自走）+ Kitty（可选复核）
结果: PASS / FAIL（列出未过项）
未过项修复后重走: [ ] 
```

## 用法
1. 开发完成 → 先跑技术 e2e（接口全通）
2. 再跑本模板 → 不过就修，修完重走
3. 两项都过 → 才提测给 Daryl（不再把 Daryl 当 Debugger）
