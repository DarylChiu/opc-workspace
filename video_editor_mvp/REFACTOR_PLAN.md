# 视频自动化剪辑MVP · 重构开发计划 v3.0

> 日期: 2026-07-25
> 原则: 分模块开发，每模块完成即自动推进下一模块（不等验收），全部完成后一次性提测
> 基线: Hooktheory BGM 结构 + 极简前端 5 节点 pipeline

---

## 架构总览

```
frontend/index.html         单文件 SPA (~2000行预计)
api_server.py               重构为模块化 API
data/
  bgm_library.db            SQLite: song_lib + phrase_lib
  bgm_structure_*.json      Hooktheory 结构缓存
config/
  pipeline.yaml             管线配置（模型、阈值、路径）
```

## M5 · Matcher 双轨匹配 + 导出（预计 3h）

| # | 任务 | 内容 |
|---|------|------|
| M5.1 | 自动匹配引擎 | BGM 乐句为槽位，素材情绪向量匹配（主情绪+副情绪+运动量+色彩） |
| M5.2 | 时长适配 | 4策略（精准/过长截取/过短拼接+调速/无素材留空） |
| M5.3 | 前端双轨时间轴 | BGM 轨（锁定）+ 视频轨（可编辑：拖入/移除/调速/trim） |
| M5.4 | 乐句变调变速 | 选中 BGM 乐句 → 滑条调 pitch/tempo → ffmpeg rubberband |
| M5.5 | 生成剪辑脚本 | JSON → ffmpeg 批处理命令 |
| M5.6 | 360p 预览 | ffmpeg 渲染 → 前端播放器（支持逐段跳转） |
| M5.7 | 1080p 导出 | ffmpeg 渲染 → Toshiba/HDD/Syncthing 目录 |
| M5.8 | Syncthing 推送 | 输出文件自动出现在 Syncthing 目录，同步到 Tab S8 |

**自检:** 全流程走通：选歌 → 自动匹配 → 调一两个槽位 → 360p 预览 → 1080p 导出 → Tab S8 上看到文件
