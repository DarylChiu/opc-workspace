## 逐节点详解

### ① CONFIG · 配置入口
| 项目 | 内容 |
|------|------|
| **当前方式** | CLI参数、环境变量、profile预设 |
| **配置项** | 素材目录、BGM路径、输出格式(16:9/9:16)、profile选择(vlog/dance/guitar) |
| **代码** | `config.py` / `profiles/base.py` |

### ② SCAN · 素材扫描 (0.2)
| 项目 | 内容 |
|------|------|
| **输入** | 素材目录路径 |
| **处理** | 扫描视频/音频/图片文件，按创建时间戳自动分组 |
| **输出** | `MediaFile[]` + `MaterialGroup[]`（同一天/相邻时间的素材自动归组） |
| **当前交互** | 无 — 自动执行 |

### ③ BGM ANALYZE · BGM结构解析 (0.4)
| 项目 | 内容 |
|------|------|
| **输入** | BGM音频文件 |
| **处理** | madmom/librosa 检测节拍+BPM；识别Intro/verse/chorus/bridge/outro段落；计算RMS能量曲线 |
| **输出** | `BeatInfo` + `Segment[]` + `EnergyCurve` |
| **当前交互** | 无 — 自动执行 |

### ④ ASR + SCENE · 语音转写+场景检测 (0.5)
| 项目 | 内容 |
|------|------|
| **输入** | 视频素材音频轨道 |
| **处理** | Whisper STT 转写对话；检测画面场景切换点 |
| **输出** | `Transcription[]` + `SceneBoundary[]` |
| **当前交互** | 无 — 自动执行 |

### ⑤ EMOTION FUNNEL · 三层情感漏斗 (0.6)
| 项目 | 内容 |
|------|------|
| **输入** | 素材片段 + ASR文本 |
| **处理** | L1: DeepSeek对白情感 + 颜色/亮度/运动信号 → 粗筛<br>L2: 高频采样 → 信号精筛<br>L3: Gemini Vision → 深度帧级识别 |
| **输出** | `EmotionMap` — 每个片段的情绪标注 |
| **当前交互** | 无 — 自动执行 |

### ⑥ MATCH · BGM-素材匹配编排 (0.7) ★核心心脏
| 项目 | 内容 |
|------|------|
| **输入** | BGM段落 + 素材片段 + 情绪映射 |
| **处理** | ① 情绪兼容性匹配(BGM情绪↔画面情绪)<br>② 节拍对齐(切点落在BGM强拍/段落边界)<br>③ 时长适配 |
| **输出** | `Timeline` — 完整的剪辑时间线 |
| **当前交互** | 无 — 全自动匹配 |

### ⑦ VLOG EDIT · Vlog剪辑编排 (0.8)
| 项目 | 内容 |
|------|------|
| **输入** | Timeline + 原始素材 |
| **处理** | BGM驱动节奏控制；人声保留+自动音量调节；crossfade转场 |
| **输出** | `VlogEditPlan` — 含转场、音量、速度的最终编排方案 |
| **当前交互** | 无 — 自动编排 |

### ⑧ PREVIEW RENDER · 预览渲染 (0.13)
| 项目 | 内容 |
|------|------|
| **输入** | VlogEditPlan |
| **处理** | 720p 快速预览渲染（可只渲染前N秒） |
| **输出** | 预览MP4文件 |
| **当前交互** | 🔴 决策点 — Agent/用户查看预览，决定通过/调整/重来 |

### ⑨ OUTPUT PIPELINE · 多格式输出 (0.9+0.10+0.11+0.12)
| 项目 | 内容 |
|------|------|
| **输入** | 确认后的VlogEditPlan |
| **处理** | 并行渲染6个MP4(16:9/9:16×full/30s/15s)；MediaPipe人脸追踪智能9:16裁剪；Whisper文本→双语SRT字幕；Hook自动提取+封面图 |
| **输出** | 6 MP4 + SRT + Hook + Cover |
| **当前交互** | 无 — 一键输出 |

### 「灵动感」可能的根因分析

当前 Phase 0 管线是全自动「一条龙」——用户/Agent在步骤⑧预览节点才能看到结果。在此之前，步骤②~⑦的所有决策（素材分组、BGM段落切分、情感分析、素材匹配、剪辑编排）都是黑盒自动执行。

**「灵动感」缺失的可能来源：**
1. **匹配算法过于保守** — 情绪兼容性匹配偏向「安全」选择，缺少惊喜感
2. **剪辑节奏单一** — Vlog Editor的节奏策略可能偏匀速，缺少变速/快切/停顿
3. **BGM段落切分粒度** — 当前分段可能不够精细，导致画面切换不够「踩点」
4. **素材选择缺少「亮点」优先** — 可能选了平均但不精彩的片段
5. **缺少人工直觉干预点** — 全自动管线没有给创作者留「我想要这个片段用在这里」的入口
