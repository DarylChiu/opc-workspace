## 1. ➕ 目录浏览器

- **位置**: 右上角增加「+」按钮
- **行为**: 点击弹出模态窗口，左侧目录树 + 右侧文件列表
- **根目录**: `/Volumes/TOSHIBA EXT/Video/Raw Materials/Insta 360/`
- **内容**: 显示子文件夹 + .mp4 文件
- **交互**: 点击一个素材 → 加入「待分析素材」列表，关闭弹窗
- **后端**: 新增 `GET /api/scan/browse?dir=...` 端点

## 2. 素材卡片显示

### 2① 文件名格式
- **格式**: `YYYYMMDD_xxx.mp4`（如 `20260507_001.mp4`）
- **不显示**: 拍摄时钟时间（无价值）
- **说明**: 从原始文件名 `VID_YYYYMMDD_HHMMSS_xxx.mp4` 中提取日期段和序号

### 2② 卡片内视频预览
- **触发**: 先点击素材卡片（非展开）
- **效果**: 最低画质和帧率在卡片内直接播放
- **技术方案**: 服务端惰性生成 + 缓存
  - ffmpeg 转码: 160×90, 8fps, 极低码率, 无音频, ~5s片段
  - 生成一次 → `data/previews/` 缓存，后续秒开
  - 首次生成 2~4s，显示 loading 转圈
- **页面影响**: 按需惰性加载，不影响网页首次加载性能

### 2③ 选取/不选取切换
- **默认状态**: 加入列表时均为「已选取」
- **交互**: 单击卡片切换选取/不选取
- **不选取样式**: 灰色（opacity + grayscale）
- **不选取行为**: 不可预览，下一步 ASR + 场景识别跳过此素材
- **实现**: 纯前端状态管理 `Set`，CSS 类控制

## 3. 设计约束
- 本模块定位：文件选取器，不扩展额外功能
- 沿用 OPC Design System 样式变量
- 与 BGM 模块保持视觉一致性
