# 规则卡 H2｜客诉免费补货

**项目** FOC-VN｜**场景** Huatex OUT 线｜**版本** v1（2026-10-07）｜**编制** Self

**适用事实**：生产失误/不良率高/QA 抽验不足 → 客诉 → 销售直接免费送新品 → 库存出库 → 报关（海外客户 或 越南 DNCX）｜**不收款**｜**不回收旧品**

> ⚠️ **本版更正（v1.1，答 Daryl 两问后）**：早前一处说法「促销/赠送不合规 → 既补销项、进项亦可能被要求转出」**在当前法下不准确**。
> 据 **Luật 48/2024/QH15 Điều 14 khoản 7**，用于 `cho, biếu, tặng, khuyến mại, quảng cáo` 的货物**进项可抵扣** → **不存在「双罚」**：销项要交，进项照抵。

> **一句话规则**：这批货**不是销售**（不确认收入），**但要开票、要计销项**——计税价按**同类/等价商品市价**；存货成本＋销项税**全额进销售费用**。

## 2｜VAT

| 项 | 结论 |
|:---|:---|
| **定性依据** | 无偿转移货物 → **Luật 48/2024/QH15 · điểm c khoản 1 Điều 7**：用于 `cho, biếu, tặng` 的货物，**按同类或等价商品的计税价**计缴 VAT（`tính nộp thuế GTGT như hàng hóa bán ra`） |
| **计税价** | **同类/等价商品市价** —— ❌ 不是成本价、❌ 不是 0 |
| **税率** | **8%**（减征期 2025-07-01 ~ 2026-12-31，NQ 204/2025/QH15 + NĐ 174/2025）※面料是否在除外清单见 §7 |
| **能用出口 0% 吗** | ⚠️ **两条路都开着，取决于定性——我前两版分别说过头过两次**（先「走不通」、后「存疑」）。<br>**法定机制**：NĐ 181/2025 **Điều 18** 三条件（①合同 ②非现金支付凭证 ③报关单），**缺任一条 → 不适用 0% → 按内销计税**（此为越南法**明文机制**，旧法为 TT 219/2013 Điều 17，现由 Luật 48/2024＋NĐ 181/2025 承接）<br>**争取路径（新增，重要）**：若把 H2 定性为「**履行已收款的销售合同（质量赔付）**」而非「无偿赠送」，则**原订单的银行收款凭证**可能充当 ② 的支付凭证要素，＋合同质量条款补强 ① → **0% 有可能站住**<br>**回落路径**：若税局不接受 → 按内销计税（8%×同类市价）<br>→ 二选一必须先取税局书面口径，见 **§7c** |
| **三种「invoice」要分清** | ① **PI（Proforma / hóa đơn chiếu lệ）**：无法律效力，不是税票<br>② **Commercial Invoice（商业发票 / hóa đơn thương mại）**：国际贸易与报关用，**仍不是越南税务发票**<br>③ **hóa đơn GTGT / hóa đơn xuất khẩu（越南电子发票，税率 0%）**：**只有这一张才是越南的税务主张**<br>→ ❓**待你确认**：你说的「0% 的正式 invoice」是 ② 还是 ③？两者法律地位完全不同 |
| **PI 上的 0%** | ⚠️ **PI（Proforma Invoice / hóa đơn chiếu lệ）不是税务发票、无法律效力**：不是正式结算发票、不产生付款义务、不能作为有效凭据。PI 写 0% ＝**商业表述**（出口报价不含 VAT），**不决定也不证明税务处理**。决定税务的是：**出口发票 ＋ 报关单 ＋ 合同 ＋ 支付凭证** |
| **能用「计税价 0」吗** | ❌ **不适用**。那是**合规促销送样**的口径（NĐ 181/2025 khoản 2 Điều 6 điểm a），**客诉赔付不属促销** |
| **进项税** | ✅ **可以抵扣**——**Luật 48/2024/QH15 · Điều 14 khoản 7** 明列：用于 `cho, biếu, tặng, khuyến mại, quảng cáo` 的货物（含外购与自产），其**进项 VAT 得抵扣**。采购环节已抵，**本环节无需转出** |
| **申报** | ✅ **开票后必须在开票所属期申报**：计入 01/GTGT 销项，并列入销项发票清单（bảng kê hóa đơn bán ra）。无偿转移的**纳税义务时点＝交付时点**，**未收款不构成不申报的理由**；电子发票已实时上传税局，**系统自动比对** |
| **填哪一行** | ❌ **不填「0% 出口应税收入」那行**；✅ 填**该货物适用税率那一行（8%）**。依据：CV 90157/CT-TTHT——赠客户的 10% 税率货物按该税率对应指标（旧版 01/GTGT 为 **[32][33]**）申报；实务多家一致。※ 2026 年若已按新表样换版，**指标号需按现行表样核对** |
| **⚠️ 填错行的后果** | **填 0% 行＝向税局主张「这是符合条件的出口」**。主张不成立（缺合同＋支付凭证）→ **0% 被否 → 按同类/等价市价补 8% 销项税 ＋ 滞纳金（0.03%/天）＋ 罚款**。**这不是「最多罚款」——补税本身才是主项** |
| **能退税吗** | ❌ **不能**。退税只适用 **0% 出口经营**（且未抵进项 ≥3 亿 VND，Luật 48/2024 Điều 13）；本场景 0% 拿不到 → **无退税资格，只能抵、不能退** |
| **开票** | ✅ **必须开电子发票**（NĐ 70/2025 修订 NĐ 123/2020 **第 1 条第 3 款**明列 `hàng mẫu; cho, biếu, tặng` 须开票）；票面注明**赔付性质**、按同类市价 |

## 2b｜⚠️ 概念澄清：进口侧的 0% 与出口侧的 0% **不是一回事**

| | **进口侧（供应商开给你的发票 0%）** | **出口侧（你自己开出去的发票 0%）** |
|:---|:---|:---|
| 这个 0% 是什么 | **对方国家（出口国）的出口零税率**——是**境外事实** | **越南自己的税收待遇**（`hàng hóa xuất khẩu`） |
| 越南税局要不要审 | ❌ **不审**（与越南税无关） | ✅ **必审**，`NĐ 181/2025 Điều 18` 三条件（合同＋银行支付凭证＋报关单） |
| 越南的税在哪里 | 在**海关进口环节**另行征收进口 VAT（计税价＝进口价＋关税＋消费税＋环保税），**由进口方申报缴纳**，凭海关缴款凭证作进项抵扣 | 在**你的销项**里：适用 0% 或按内销计税 |
| 为什么"看起来就可以" | 因为**它不是越南的税**；越南只关心自己这一环 | 因为 **0% 出口 → 进项可退**（`Luật 48/2024 Điều 13`，未抵进项 ≥3 亿 VND）→ **国家要放钱出去，所以必须严管证据** |

> **一句话**：**被审的永远是开票方（纳税义务人）。** 你们的海外客户拿到你们 0% 的发票，对**他们**也"就可以"——因为对他们而言那只是境外事实。
>
> ⚠️ **另一条要澄清的可能**：若你们进口侧是「**加工出口企业免进口税/免进口 VAT**」（保税/加工出口机制），那也"可以"，但**那不是"没有条件"，而是条件由海关管、且你们日常在做**（免税目录、定额、台账、结转报告、不得内销）——**同样是"三条件"式监管，只是换了主管部门**。
> 出口侧真正缺的不是"条件这个形式"，而是**「支付凭证」这一条**（因为不收款）。

## 2c｜越南 VAT 到底挂在哪几样凭证上（PI / CI 不算）

> **一句话**：越南 VAT 只认 **「越南税票 ＋ 海关凭证 ＋ 银行凭证 ＋ 合同」**。**PI 完全不算数；CI 不算「税率」，只算「金额」和「交付证据」。**

| 方向 | 法定凭证（缺一不可） |
|:---|:---|
| **Input（进项抵扣）** | ① **越南 `hóa đơn` GTGT**（国内采购）**或** **海关进口缴款凭证 `chứng từ nộp thuế GTGT khâu nhập khẩu` ＋ 报关单**（进口）<br>② **非现金支付凭证**——现行门槛 **≥ 5,000,000 VND**（**2025-07-01 起**，已由 20 triệu 降为 5 triệu）【多源一致·条文待核】<br>③ 用于**应税**经营活动 |
| **Output（销项申报）** | ① 你开的 **`hóa đơn`（越南电子发票）**<br>② **纳税义务发生时点**（交付时，非收款时）<br>③ **计税价规则**（`Luật 48/2024 Điều 7`） |

### ⚠️ CI（Commercial Invoice）的两个「不是」，和一个「是」

| | 结论 |
|:---|:---|
| CI 的**税率栏/税款栏** | ❌ 与越南 VAT **无关**（那是出口国税制，不是越南的税） |
| CI 的**金额** | ✅ **进口侧它是进口 VAT 的计税基础**！计税价 ＝ **进口价（CI 金额）＋ 关税 ＋ 消费税 ＋ 环保税** → **决定税基，不决定税率** |
| CI 在**单据链** | ✅ 是**交付/出境证据**（出口 0% 举证、海关申报都要它）→ **不决定税率，但参与举证** |

> 📌 **本次新增的合规提示（近期收紧）**：进项抵扣的「非现金支付」门槛**自 2025-07-01 起由 2,000 万降为 500 万 VND** → **更多交易现在必须有银行凭证**。建议财务部**复核 2025-07-01 以后期间**是否存在 ≥500 万 VND 的现金/非银行结算采购（会直接踩掉进项）。

## 7b｜申报方式的选择（**不是自由选择，是哪个合法**）

| 申报方式 | 当期现金流 | 稽查后果 |
|:---|:---|:---|
| **填 0% 出口行** | 不交税 | **0% 被否 → 补 8% 销项＋滞纳金＋罚款**；且若同时已开 8% 发票，**发票与申报表不一致 → 系统比对直接异常** |
| **填 8% 行（按同类市价）** | 交 8%×市价 | 主动按法条申报，无隐蔽；进项可抵（Điều 14 k7）→ **净成本＝8%×市价** |
| 口徕乙（有报关单但缺凭证） | 不计销项 | 但**进项不得抵扣**（需转出）→ 两条路金额不同，**必须取税局书面口径**（Q1/Q2） |

> ⚠️ **两个硬约束**：①**发票与申报表必须一致**（电子发票实时上传，差异自动拦截）；②**不能「先填 0% 省现金流、等稽查再说」**——滞纳金 0.03%/天 ≈ 年化 11%，长期暴露成本高于当期税款。

## 7c｜单据链一致性（**比单看税率更致命**）

FOC 出口涉及四份文件，必须互相自洽；断层就是稽查入口：

```
PI（商业·无法律效力）── 只说明商业安排
     │
出口发票（税务）───── 税率？ 0% 或按内销
     │
报关单（海关）────── 按「出口」申报
     │
01/GTGT 申报表 ─────── 填在哪行？
```

| 组合 | 是否自洽 | 风险 |
|:---|:---|:---|
| PI 0% ＋ 出口发票 0% ＋ 报关出口 ＋ 申报 0% 行 | **自洽** | 但 0% 三条件若被否，**整体被推翻** |
| PI 0% ＋ 出口发票 8% ＋ 报关出口 ＋ 申报 8% 行 | ✅ **合法组合（已更正）** | **「货物出境 ＋ 按内销计税」是越南法明文后果**，不是口径冲突 |
| 不开票 / 不开票又不申报 | ❌ 违规 | **无退路**（电子发票系统比对） |

> ⛔ **本版更正（我上一版说错了）**：上一版我写「报关出口 ＋ 按 8% 比全按 0% 更危险，因为海关与税务两套口径打架」——**这个说法是错的**。
>> 越南法**明文规定**：出口货物**单据不全 → 按内销计税**（TT 219/2013 Điều 17；现由 Luật 48/2024 ＋ NĐ 181/2025 承接）。也就是说，**「货物出境」与「是否适用 0%」本来就是两件事**，「出口了但按内销计税」是**法定后果**，不构成两套账冲突。
>> ✅ 正确判断：**问题不是「口径打不打架」，而是「这批货适用 0% 还是按内销」——二选一，且必须口径全程一致**：
>> · 适用 0% → 发票 0%、申报 0% 行、单据链补至满足三条件
>> · 不适用 0% → 发票按内销 8%、申报适用税率行（**与报关单并不冲突**）

### 🔎 必须由 Huatex 核实的三件事实（我查不到——不在公开法源里，只在公司单据里）

| # | 问题 | 为什么要问 |
|:--|:---|:---|
| F1 | **FOC 的 PI 上写的是什么？**「0% 税率」还是「FOC / No Charge / 单价 0」？ | 两者含义完全不同：前者像报税声明，后者是商业条款 |
| F2 | **FOC 实际开的是哪种税务发票？** 出口发票 0% / 内销发票 8% / **没开票**？ | 决定当前申报口径是否自洽 |
| F3 | **历史上 01/GTGT 是怎么填的？** 0% 出口行 / 适用税率行 / **未申报**？ | 决定**已暴露面**（追溯期内金额、滞纳金、罚款） |

> 这三件一给，我就能立刻算三件事：**①当前口径是否自洽 ②已暴露面多大 ③「照旧」 vs 「纠正」两条路各自的代价**。

## 7d｜回落到内销计税：要多承担多少？进项还能不能抵？

### ① 多承担的销项税（相对 0% 的增量）

```
增量销项税 = Σ(各批【同类/等价商品市价·不含VAT】) × 税率
税率：8%（减征期至 2026-12-31）｜若面料在减征除外清单 → 10%
```

- **快速换算**：每 **100 万 VND 市价 → 多承担 80,000 VND**（按 8%）
- ⚠️ **计税价是「市价」，不是成本价**——用成本估会**系统性低估**（税局会按同类/等价市价核定）
- 另加：**滞纳金 0.03%/天**（自应申报期起算）＋ 可能的行政处罚；追溯期按税收管理法核（**待核**）
- ❓**要算实数，需要两项业务数据**：① FOC 出库的总额（**市价口径**，非成本）② 期间分布（判断滞纳金起算与追溯期）

### ② 进项能不能抵？—— **能，而且这条是法条明文**

> **`Luật 48/2024/QH15 · Điều 14 khoản 7`**：用于 `cho, biếu, tặng, khuyến mại, quảng cáo` 的货物（含外购与自产），其**进项 VAT 予以抵扣**。

⚠️ **但要纠正一个隐含前提**：进项**不是「因为承担了销项税才变得可抵」**——它**本来就可抵**（原材料用于生产经营；且上述条文把 `cho/biếu/tặng` 明确列入可抵范围）。

**销项与进项是两笔独立判断，不是交换关系。** 所以：

```
净成本 = 销项 8% × 市价        （进项既非新增收益，也不能退）
```

**两个例外（会打掉进项）**：① 若被认定为**非经营用途** → 进项须转出（客诉赔付属经营相关，此风险低）② 采购时**缺凭证**（如现金结算 ≥500 万 VND）→ 进项被剔，与销项无关

### ③ ⛔【已否决·留痕】「象征性对价」方案（我提的，Daryl 驳回，我认错）

**原提议**：让客户支付象征性对价（1 USD / 承担运费）→ 取得「非现金支付凭证」→ 补齐 0% 的 ② 要素。

**Daryl 驳回原话（2026-10-07）**：「③是你能想得出来的？那原本同类产品申报按10usd，突然按1usd，无论是海关申报还是税务申报都很大风险啊」

**为什么这个方案是错的（三层）**：

| # | 问题 |
|:--|:---|
| 1 | **达不到目的**：象征性对价不会让交易变成「有偿销售」，**法律实质仍是无偿转移** → 税局照样按同类市价计销项 → 0% 目的落空 |
| 2 | **新增海关风险**：同一产品平时申报 10 USD，这批按 1 USD → **申报价值与同类产品严重偏离** → 申报不实/估价质疑（并波及统计、后续复进口、关联交易口径） |
| 3 | **新增税务风险**：售价显著低于市价 → 税局有权按市价核定；且可能被认定为**形式上规避** |

**我错在思路上（不只是错在方案上）**：
> 我把「支付凭证」当成一个**要凑齐的单据要素**（技术问题），但它真正的法律意义是——**证明这是一笔真实的、有偿的出口销售**。
> **凑一张纸 = 规避；把业务事实改成有偿 = 安排。** 这两者的区别我没分清。Daryl 一句话点破。

---

### ③′ 正确的方向（若未来想走 0%）：**改业务事实，不改申报数字**

> 把免费补货定义为 **销售合同项下「价格已内含的交付义务」**（例如合同约定按订单量 X% 提供免费补货、或质量保证项下的备品），
> 而不是「额外的无偿赠送」。

这样三条件**自然齐备**：

| 要件 | 来源 |
|:---|:---|
| ① 合同 | 销售合同中的**免费补货条款** |
| ② 非现金支付凭证 | **正常订单的银行收款**（该批货的对价已内含在销售价格里） |
| ③ 报关单 | 出口报关 |

- ✅ **这是实质业务安排，不涉申报数字造假**
- ⚠️ 仍需税局确认「合同项下免费补货能否构成销售合同项下交付」→ **列入待咨询清单**
- ⚠️ 代价：**合同要改** → 又一次回到「反推业务部」
- ❌ **不适用于 2026-09 以前**已发生业务（无法追溯制造支付关系）

## 8｜稽查会看哪 5 点

1. **有没有开票**（不开票＝最直接命中）
2. **计税价用了哪个数**（用成本价或 0 顶替同类市价 → 直接补税）
3. **单据链是否闭合**：客诉 → 检验 → 审批 → 出库（标 FOC）→ 签收
4. **有没有误用出口 0%**（缺合同/支付凭证而主张 0%）
5. **A/B 口径是否前后一致**（同一批业务两种做法＝自曝）
