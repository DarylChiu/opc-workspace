## 2. 判定闸门决策树（全流程的岔路口）

```
闸门 G1 · 收不收款？
  ├─ 收款 ……………………… 有偿维修/换件 → 开票 + 收入 + 销项（P2-A0）
  └─ 不收款 → FOC 主流程 ↓

闸门 G2 · 开票形态？（决定 S4 单据链）
  ├─ 收了款 ………………………… 必须开票（同销售）
  ├─ 在保 + 零部件/维修 ……… 不开 VAT 票，走内部单据
  ├─ 在保 + 整机换新
  │    ├─ 原票可追溯 ……… 退货/调整票 + 新货票（双票）
  │    └─ 原票不可追溯 …… 收回原票分支 / 内部单据分支（细节待核）
  ├─ 合规促销送样 ……………… 开 0 价电子发票（计税价 0）
  ├─ 非合规赠送 ……………… 按同类市价 + 销项（丧失计税价 0 特权）
  └─ 员工福利 ………………… 按福利口径开票（CIT/PIT 另议）

闸门 G3 · 跨境税负路径？
  ├─ 进口免费货 … 小额进口 VAT 免税据报已停止执行（**决定文号与生效日均待核**，
  │                检索线索见 §7.2）→ 逐条核免税情形
  └─ 出口免费货 … 三条路径并存（内销计税 / 主张 0% / 计税价 0），
                  官方无直接口径 → P1 决策点，待 Daryl 拍板

闸门 G4 · 对方是谁？（决定 PIT / 转让定价）
  ├─ 客户 ……………………… 促销口径
  ├─ 员工 ……………………… 福利口径 ⚠️分支结论待定（PIT 口径未决，
  │                          P2 回一手原文前不得据此入账）
  └─ 关联方 ………………… 触发转让定价，超出本项目范围
```
