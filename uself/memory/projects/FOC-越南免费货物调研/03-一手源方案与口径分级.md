## 3. 口径分级（每条规则必须标）

| 级别 | 含义 | 可用性 |
|:---|:---|:---|
| **A｜法定条文** | 已回一手原文（含款项文字） | 可直接作为规则依据 |
| **B｜官方答疑** | 税务总局/地方税务局/海关公函口径 | 可作为实务依据；须核其在现行法下的效力 |
| **C｜实务一致** | 多个独立二手源一致，无 A/B | 可写入规则，但必须标「非官方」 |
| **D｜无口径** | 找不到 A/B/C | **不得作为结论**；只能列为「待咨询税务机关」，并给出可选路径与风险 |

## 4. 每条规则的固定输出格式

```
【场景】H2 客诉免费补货 / 报关出口 / 供越南 DNCX / …
【法律事实】…
【A 法定条文】条款号 + 原文摘录 + URL + 抓取时间
【B 官方答疑】文号 + 日期 + 口径 + URL（或「无」）
【C 实务解读】多源一致？来源列表
【VAT 处理】路径 + 依据级别
【会计处理】分录（VAS/TT 99/2025）+ ★是否确认收入
【CIT 处理】★是否确认收入 + 费用扣除要件
【申报】表种 + 时点
【风险】稽查入口 + 高频错点 + 争议点
【置信度】A/B/C/D
【需 Daryl 决策】… ｜【待咨询税务机关】问题清单见 §5
```

## 6. 无口径场景的处理原则

1. **不站队**：并列呈现各口径（如 0% 失守的「按内销」vs「不计销项＋进项不得抵扣」），标注各自后果。
2. **给可选路径 + 风险分级**，不给单一答案。
3. **明确标注「需书面确认」**——凡涉金额重大或可被处罚的，建议向主管税务机关取书面答复。
4. **绝不填稻草**：找不到口径就说找不到，绝不拿训练数据当法条。

## 7. 本次演示（不依赖 Daryl 任何资料，已验证可自行取到条款）

**NĐ 181/2025/NĐ-CP · Điều 18 —— 出口 0% 的三条件（多方一致，2026-10-07 检索）**

> 出口货物适用 0%，须具备：
> ① **合同**（销售/加工出口合同；委托出口则为委托出口合同）
> ② **非现金支付凭证**（chứng từ thanh toán không dùng tiền mặt）
> ③ **有效报关单**（tờ khai hải quan hợp lệ）
> 服务出口另有 khoản 3/4/5 例外；特例见 Điều 27 / Điều 28。

**对 FOC 的直接杀伤**：免费出货**既无销售合同、又无支付凭证** → **三条件里两条不成立**。这比我 v0.5 里写的「FOC 必然缺支付凭证」更严重，**是本项目最硬的一条约束**。

### 7.2 第二次演示：50 USD 快递到底有没有报关（2026-10-07）

> Daryl 补充事实：「货品价值低于 50 USD 时，DHL 或 FedEx 没有正式报关处理」；但到底是 ①完全无手续还是 ③低值简易申报，他不确定。

**核查结论：很可能是 ②——「报关不在你名下，但报关很可能发生了」。**

| 发现 | 来源 |
|:---|:---|
| FedEx 官方《越南出口清关指南》：**FedEx/TNT 作为出口方代表，可申报低值货物（MEC）或非贸易货物（H21）** | fedex.com（官方 PDF） |
| **H21 ＝ 出口非贸易货物（xuất khẩu hàng khác）**；H11 ＝ 进口非贸易货物 | phaata.com、reallogistics.vn |
| H11/H21 类型**无数量或价值上限** | extendmax.vn |
| 低值货物（MEC）惯常阈值：**每票 <100 万 VND**（≈ 40 USD，与你说的 50 USD 接近） | eimskip.vn（2026） |
| 低值/非贸易货物由**承运商自行申报**后交付；商业货物（kinh doanh）则企业须自行开报关单 | dhslogistic.com、tam-logistics.vn |

**→ 对本项目的影响（双向）**

| 方向 | 含义 |
|:---|:---|
| ✅ **好消息** | 可能**存在报关记录**（MEC/H21），只是不在 Huatex 名下、也没拿到副本 → **R3 的「海关违规风险」可能大幅降低**，「完全无手续」大概率不成立 |
| ⚠️ **坏消息** | 若确按 **H21（非贸易）** 申报，则相当于**官方单据本身已经证明这不是一宗「出口销售」** → 而 NĐ 181/2025 Điều 18 的 0% 三条件**全以「销售/加工/委托出口合同」为前提** → **0% 路径更难站住** |

**→ 给 Huatex 的具体动作（已列入 `04-业务侧反推清单.md` B6）**：向 DHL/FedEx 客户经理索取：

1. 该批货**有没有报关单**（tờ khai）？以谁的名义申报？
2. 申报类型是 **MEC（低值）还是 H21（非贸易）**？
3. **能否提供报关单副本 / 申报清单**？

> 这三个问题一答，H1 的税务路径就能从「待核」变成可算。
