## 卡 1 · 进口入账复核

### ① 概念边界（是什么 / 不是什么）—— 复核视角

- **是**：一张「进口入账复核清单」。回答的唯一问题是：**下属把一笔进口业务记进账里，哪几种错我一眼会拦下来。**
- **不是**：
  - 不是「进口六单据链」。❌ 11/02 修正：进口是**两条平行链**，不是一条链凑齐六张纸。
    - **物权链**（定「成不成立」）：销售确认/订单或合同 → PI 或 CI → 装箱单 → 报关单 → 提单
    - **成本构成链**（定「金额多少」）：缴款书、运费单 —— **不在物权链上**
  - 不是记账操作指南。复核视角下，「怎么做分录」是下属的事，「他会在哪一步做错」才是本卡的事。
  - 不是「单据齐了就没问题」。单据齐 ≠ 金额对 ≠ 期间对 ≠ 主体对。

**复核的四道关卡（本卡骨架）**：

| 关卡 | 复核问题 | 典型落点 |
|---|---|---|
| G1 物权成立 | 这批货的买卖关系成立吗？凭什么单据？ | 缺销售合同 → 前置关系不成立，后面全白做 |
| G2 成本归集 | 缴款书和运费进对科目了吗？进了物权链没有？ | 把成本单据混进物权链 |
| G3 期间配比 | 报关、到货、付款、结转，落在同一期间吗？ | 跨期错配 |
| G4 主体一致 | 进口主体、付款主体、记账主体是同一个吗？ | 代付/代收导致主体漂移 |

### ② 常见误判（人会犯的 + AI 会犯的，分开写）

**人（下属）会犯的** —— 来源：11/02 现场 Daryl 口述 + 复核视角推演

- G1：**只查单据张数，不查买卖关系**。六张纸都在，但没有销售合同/订单，实际上是无合同进口。
- G2：**把缴款书、运费单当成物权凭证塞进物权链**，导致「物权链齐了」的假象，成本却没进成本科目。
- G3：**期间错配**——报关在 A 月、到货结转在 B 月、付款在 C 月，三处各记各的，账面看起来都对。
- G4：**主体漂移**——A 公司进口、B 公司付款、记在 C 公司账上，三家都「有据可查」但链条断了。

**AI 会犯的** —— 来源：Self 自身失败史（11/02 现场实录 4 条 + lessons）

- ❌ **AI-1 答得太整齐**：把进口画成一张左右对称的六行映射表（单据 → 科目），而真实业务是**非对称**的（两条链长度不同、功能不同）。**人的经验是碎的、带例外的，所以不会被对称表骗。**
- ❌ **AI-2 用过时的业务形态推演现行流程**：11/02 Self 把「货没到岸就索要提单」写成人的典型错法，Daryl 纠正「供应商全给电子版，只需打印，不存在单据在海上没收到」。→ **AI 的知识有「时代戳」，但不标注哪部分已过期。**
- ❌ **AI-3 用清单代替因果链**：「六单据齐了 → 进口成立」是清单逻辑，漏掉了「销售合同是先决条件」这个因果。
- ❌ **AI-4 概念滑动**：把「物权成立」和「成本归集」两个不同问题混答成一个「进口入账」问题。
- ⚠️ **AI-5（新增，11/14 草稿阶段自检）**：把「复核视角」理解成「把记账流程倒过来写一遍」——复核不是逆流程，是**独立的一套拦截判据**，与记账步骤不一一对应。

### ③ 证据标准（看到什么就算，看不到就不算）

- **G1 成立需**：销售合同或订单 + PI/CI + 报关单，三者**主体与货物描述一致**。任一缺失 → 不成立。
  - **足够即止**：以上三者齐且一致，不必再核提单细节（提单是运输证据，不是买卖关系证据）。
- **G2 成立需**：缴款书金额 + 运费单金额 **能加总到存货成本**，且**不出现在物权链凭证组**里。
- **G3 成立需**：报关日期、到货/结转日期、付款日期落在同一会计期间，或跨期时有明确的分摊/暂估记录。
- **G4 成立需**：进口主体 = 付款主体 = 记账主体。不一致时**必须有代付/代收协议作为凭证**，否则不成立。
