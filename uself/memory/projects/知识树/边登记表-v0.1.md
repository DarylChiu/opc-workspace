## 一、字段定义

| 字段 | 含义 | 填写要求 |
|---|---|---|
| `edge_id` | 边编号 | E-001 起，永不复用 |
| `卡A` / `卡B` | 两端节点 | 用卡 id 或概念名，须能对应到 N2 清单条目 |
| `关系类型` | 对照 / 冲突 / 共犯 / 前提 | 四类，见第二节定义 |
| `一句话说明` | 这条边断言了什么 | 必须是**可被证伪的断言**，不是「二者相关」这种空话 |
| `证据锚点` | 落点 | 文号级 / 条款级 / 实测记录；无锚点写「未锚定」，禁止编 |
| `状态` | 待验 / 已验 / 已驳 | 已驳的边**保留**（证伪本身是知识） |

### 四类关系定义（沿用 11/02 STATE.md 口径）

- **对照**：两套准则对同一概念给不同答案（VAS ↔ IAS/IFRS）
- **冲突**：两层规则对同一业务给相反结论（税务层 ↔ 会计层）
- **共犯**：同一种错法在不同概念上重复出现（AI 或人）
- **前提**：A 成立是 B 成立的必要条件，A 错则 B 全错

### E-001 ｜冲突｜VAT 层计税 ↔ VAS 层不确认收入

| 卡A | 越南 VAT 三层分离（财务域 #7，已有全库唯一填满的样板卡） |

| 关系类型 | 冲突 |
| 一句话断言 | 同一笔预收/代收业务，**VAT 层按「已发生应税行为」计税，VAS 层因不满足收入确认条件而不确认收入** —— 两层结论相反，且两层都对。任何试图把二者「统一」的处理都是错的。 |

### E-002 ｜对照｜VAS 17 ↔ IAS 12（企业所得税 vs 所得税）

| 字段 | 值 |
|---|---|
| 卡A | VAS 17 企业所得税会计 |
| 卡B | IAS 12 Income Taxes |
| 关系类型 | 对照 |
| 一句话断言 | 同一「递延所得税」概念，**VAS 17 只承认部分暂时性差异、不承认重估产生的差异**，IAS 12 承认全部暂时性差异（含重估）。差异不是「谁更先进」，是**口径边界不同导致的递延税负债不可比**。 |
| 证据锚点 | VAS 17 条文（待补文号）／IAS 12 §15、§20 |
| 状态 | 待验（锚点只到准则级，未到条款；下一场现场补） |
| 出处 | STATE.md 对照边例子；11/02 现场 |

### E-003 ｜共犯｜中国概念移植三连（视同销售／免抵退／加计扣除）

| 字段 | 值 |
|---|---|
| 卡A | 视同销售禁区（财务域 #8） |
| 卡B | 免抵退 / 研发加计扣除 |
| 关系类型 | 共犯 |
| 一句话断言 | 这三个中国税制概念在越南**均无对应制度**，但错误结构完全相同：**先默认「中国有的越南也有」，再去找越南条文给它安位置**。三个错是同一个错的三个实例，所以修一个不够，必须识别「移植冲动」本身。 |
| 证据锚点 | 越南 CET 与 CIT 法（Luật 67/2025/QH15 及前身）无对应条款；11/02 现场口述 |
