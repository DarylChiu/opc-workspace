## 2｜逐项：交付了什么 / 用了什么准则 / 关键结论

### 2.1 越南会计准则（VAS）知识树

**① 交付**：VAS 23 个节点（VAS-01 现金 → VAS-29 会计政策/估计/差错），含三处深挖：`Circular-99-2025`（含 IFRS 15 对越南收入确认的影响）、`Circular-200`、`VAS-29-Errors`（四件套：估计变更/税务侧影响/分录模板/实务纠错指南）；全部与 IFRS/IAS 27 文件做对照锚定。

**② 准则/口径**：VAS 26 项准则体系 + TT 99/2025/TT-BTC（企业会计制度）+ TT 200/2014（旧制度对照）+ IFRS 对应准则；来源以 KMC / PwC Vietnam / KPMG Gap Analysis 二手权威对照为主（**A 级原文获取受限 → 分级标注**）。

**③ 关键结论**：
- VAS ≠ IFRS 的**国别化裁剪版**：差异不是「少几条」，而是**哲学差异**——VAS 会计目的紧贴税务口径（可扣性优先），IFRS 紧贴经济实质（决策有用优先）→ 同一笔交易两套账的差异是**结构性的**，不是差错。
- **VAS-29 差错更正是越南实务高频雷区**：差错分「重大/非重大 + 前期/本期」，且**会计更正与税务申报调整是两条独立时间轴**（分录模板 4 类 + 税务侧影响单独拆成一个节点，就是因为混在一起必错）。

**④ 我的判断成分**：「VAS 是税务导向」这条定性是我从十余条具体差异反推的**归纳结论**（置信：中高），不是越南官方表述。→ 见 §6-Q14。

**② 准则/规则/口径**：
- `Luật 48/2024/QH15`（VAT 法）— `điểm c khoản 1 Điều 7`（无偿转移按同类/等价市价计 VAT）、`Điều 14 khoản 7`（用于 cho/biếu/tặng/khuyến mại/quảng cáo 的货物**进项可抵扣**）
- `NĐ 181/2025` — `Điều 18` 出口 0% **三条件**：①合同 ②非现金支付凭证 ③有效报关单，**缺一不可**
- `NQ 204/2025/QH15` + `NĐ 174/2025` — 8% **减征税率**（2025-07-01~2026-12-31，**且有除外清单**）
- `TT 99/2025/TT-BTC`（会计科目：641/155/156/3331）｜`CV 90157/CT-TTHT`（申报行次）｜`Luật 108/2025/QH15` + `NĐ 254/2026`（税管）
- 海关侧：MEC/H21 申报类型、加工贸易链（NĐ 134/2016、TT 38/2015）

**③ 关键结论**：
1. **H2（客诉免费补货）定性：不是销售 → 不确认收入，但要开票、要计销项**；计税价 = **同类/等价商品市价**（❌成本价 ❌0）；存货成本+销项税**全额进 641 销售费用**。
2. **进项可抵，不存在「双罚」**（早前版本说「销项补、进项也转出」是**错**，已按 `Điều 14 khoản 7` 更正）。
3. **0% 有两条路，取决于定性**：若定性为「**履行已收款的销售合同（质量赔付）**」→ 原订单银行收款凭证可充当条件②、合同质量条款补强条件① → **0% 可能站住**；否则 → **回落按内销 8%×市价**。**必须取得税局书面口径后才定案。**
4. **三种 invoice 必须分清**：PI（无税务效力） / Commercial Invoice（报关用，仍不是越南税票） / hóa đơn GTGT（唯一税务主张）。
5. **申报填错行的后果不是「最多罚款」**：填 0% 行 = 向税局主张「这是合规出口」，主张不成立 → **补 8% 销项税 + 滞纳金 0.03%/天 + 罚款**，补税本身才是主项。
6. **H1（开发样品）：费用化进研发费用，不作资本化**（Daryl 判断：资本化所需单据难度大 → 弃用）。
7. **未报关是最大风险源**：无报关单 → 条件③不满足 → 默认按内销计税；且若官方单据按 **H21（非贸易）** 申报，等于**官方文件自己证明这不是「出口销售」** → 0% 更难站住。
8. **⛔ 已被否决的方案（留痕）**：「象征性对价 1 USD / 客户承担运费」→ Daryl 驳回，**三层错误**：①法律实质仍是无偿转移，目的落空 ②10 USD 平时申报、这批按 1 USD → 海关估价质疑、波及其他口径 ③售价显著低于市价 → 税局可按市价核定 + 可能认定形式规避。**我的错在把「支付凭证」当单据要素凑，而它真正意义是「证明这是真实有偿出口销售」。**

### 2.6 中越 / 新越跨境财税对比

**① 交付**：`Cross-Border/`5 节点——`VAS-vs-IFRS-Philosophy`、`Three-Jurisdiction-FS-Tax-Coupling`（越南/中国/新加坡）、`CIT-Overprovision-Reversal-Comparison`、`Commonwealth-Tax-Error-Prohibition`、`FutureTextile-Wellname-股东借款利息处理`。

**② 准则/口径**：VAS / IFRS / CAS（中国）三套 + 三国 CIT 与差错禁止原则（Commonwealth tax error prohibition）。

**③ 关键结论**：
- **「报表-税务耦合度」是选法域的核心变量**：耦合越紧（VAS/VN），会计处理即税务处理，容错低、调整要做在当期；耦合越松（IFRS/SG），会计与税务各走一套，容错高但**双轨维护成本**高。
- **CIT 多提冲回的跨国差异**：同一笔多计提，在越南与在中国的冲回时点与税务处理不同 → **跨境合并报表必须先统一「冲回口径」再合并**。

**④ 我的判断成分**：耦合度模型是我的框架（**原创，n=3 法域，未验证**）。→ §6-Q14。

缺：你**倾向**哪条，以及为什么——是单笔金额小不值得争、客户是 EPE（DNCX）有特殊性、还是**不想在系统里留下「无偿赠送」的定性记录**（这个定性会污染后续所有同类业务）？
影响：定 0% → 规则卡要加「合同补强 + 取证清单」；定内销 → 加「按月汇总申报 + 费用化口径」。

**Q2｜「象征性对价 1 USD」被你驳回后，转向「补强合同质量条款」——这条在越南实务中你验证过，还是只是相对最优？**
已知：你驳回的三层理由（实质仍无偿 / 10 USD vs 1 USD 申报价值偏离 / 税局可按市价核定）。
缺：**事后补签/补强质量赔付条款，越南税局对「追溯适用」的接受度**——你实际遇到过接受或拒绝的案子吗？
影响：这决定规则卡是把它写成「可行路径」还是「理论路径，实务慎用」。

**Q3｜「部分未报关」的真实操作通道是什么？**
已知：H1 有部分未报关（走快递）；若按 H21（非贸易）申报，等于官方文件自己否定「出口销售」。
缺：快递出境走的是商业报关 / 低值免税 / 随身携带？**业务为什么不上报关**——成本、时效、还是没人管？我们实际是否已按 H21 申报过？
影响：决定风险等级是「程序瑕疵」还是「定性反证」，两档差别巨大。

**Q4｜如果税局按内销核定补税 + 滞纳金，公司内部由谁签字承担这个风险？**
已知：补税是主项、滞纳金 0.03%/天、罚款另计。
缺：这笔风险的**承担人和容忍额度**——是财务兜、业务兜、还是老板一次性认？
影响：决定我在资产包里给「争取 0%」还是「安全路径」的建议强度。**没有这个答案，任何方案建议都是不负责任的。**

**Q5｜H1 样品选「费用化研发」而非「资本化摊入后续订单」，真实障碍是哪张单？**
已知：你的理由是「单据难度较大」，故弃用资本化。
缺：具体缺的是**研发项目立项文件 / 内部领用单 / 打样与订单的勾稽证据**中的哪一个？还是审计/税局曾经质疑过？
影响：决定资产包要不要单列一份「样品单据 SOP」——如果障碍是单据，那这本身就是可卖的能力。

**Q6｜客诉免费补货「不回收旧品」是商业决定还是客户要求？**

缺：这是运费/客户不愿退回/旧品无残值，哪一类？
影响：「质量赔付」定性要求「赔付与原瑕疵对应」，**旧品不退回会削弱因果链**。要不要建议改为「拍照+报废确认」替代退回。

**Q7｜FDI 在你心里本来是一棵独立树，还是就有意拆成案例？**

缺：你的原意——FDI 是主干（我漏了）、还是案例式更好（那我要在资产包里说明「案例式」是设计而非缺失）。
影响：直接决定我 10 月备料要不要补一棵 FDI 主干。

**Q8｜VAS-26 关联方披露这套东西，实际服务对象是谁？**

**Q9｜Future Textile 方案 C（可转换工具 + 附条件利息「自始未产生」）是你/我推的还是 A&C 提的？越南税局有先例吗？**
