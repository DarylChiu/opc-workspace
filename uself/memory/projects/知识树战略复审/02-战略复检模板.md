# 战略复检模板 v1

> **触发式使用，不做定期**。触发条件见 `01-推进面板.md`（连续 2 周命中跑偏信号）。
> 沿用 grill-me 协议：**一次只问一个**，每题 Self 先给推荐答案与理由。

## 前置（Self 必做，不占 Daryl 时间）

1. **先查工作区，再开口**——能在文件/日志/实测里查到的事实，不问 Daryl。
2. **先读上一次纪要**：`memory/projects/知识树战略复审/00-战略复审纪要-v1.md`（或最新版）。
3. 把「已确认决策」逐条对照现状，标出**已失效**的条目。

## 8 问骨架

| # | 议题 | 问的是什么 |
|---|---|---|
| Q1 | **目标** | 这棵树/这件事现在服务哪几个目标？有无新增/失效？ |
| Q2 | **成功标准** | 每个目标的验收条件是什么？能不能被第三方检验？ |
| Q3 | **产出形态** | 交付物是「判断卡」还是「操作教程」？（防退回知识层） |
| Q4 | **度量口径** | 关键指标的分母/分子定义清楚了吗？口径摆动幅度多大？ |
| Q5 | **时钟与节奏** | 有几种活动节奏？它们会不会抢同一个资源？ |
| Q6 | **出口条件** | 每个阶段的「完成」怎么判定？有无硬上限或预警线？ |
| Q7 | **验证归属** | 哪部分只能由 Daryl 判断？哪部分 Self 能独立做完？ |
| Q8 | **资产形态** | 最终的资产是什么形态？谁来验收？会不会退化为自我欣赏？ |

## 固定的三件输出

1. **已确认决策**（带日期与来源）
2. **Self 本轮挑出的结构性矛盾/数据反驳**（本次 8 问里挑出 3 处矛盾 + 1 处数据反驳）
3. **Self 认领的默认值**（可随时推翻）——**不写「待签字」**

## 红线（写死）

- ❌ **不搞签字仪式**：共识不需要仪式；需要的是「Self 给的默认值 + Daryl 随时推翻的权利」。
- ❌ 上报 Daryl 只限三类：**①不可逆 ②占他时间 ③成本/红线**。其余默认值 Self 认领，错了改。
- ❌ 不做「活动汇报」，只做「产物汇报」——防 S5 幻觉式合规。
