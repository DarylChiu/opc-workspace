## 一、三条核心改动的落地方式

### 1. 四方合同角色拖拽构建
- 左栏 7 个主体（Huatex / HFGI / 其他海外公司 / 越南 EPE / 越南本地非 EPE / 越南本地代工 / 保税仓），HTML5 drag&drop + 点选后点槽位双通道。
- 4 个槽位（销售方 / 购买方 / 供货方 / 收货方）可替换、可单格清空、整组重置；「收货方同购买方」勾选后收货方随购买方联动。
- 保税仓仅允许作收货方，违规拖入 → toast 拦截且不写入。
- 8 个预设按钮一键填充，并记录「当前预设」高亮。
- 三流图按四槽位实时重绘：节点带主体名 + 角色标签，货物流连线标报关代码（出口报关 / E62 / 无），发票流连线标 VAT 率。

### 2. 判定引擎
- 规则是**可编辑数组**（`CFG.rules`），不是硬编码；token 语法：`*` 任意、`^buyer` 同购买方、`#overseas/#epe/#vn/#cmt/#bonded` 属性类、`@id` 指定主体。
- 按顺序比对四个角色，命中即输出；`DUAL` 输出结构双解（S1-08 / S1-09 并排 + 「需二选一」+ 可切换查看两条流程）。
- 全不命中 → 「未定义组合」🔴 + 最接近模式（按命中角色数打分）+ 逐条缺失要件（含当前主体与要求主体的对照）+ 该模式口径作参照但标注「不可直接套用」。
- **与任务书的一处差异（主动披露）**：任务书 7 条规则不含「Huatex 售境外买方 + 货交 EPE」这一组合，而任务书给定的 S1-09 预设正是该组合。为让预设能自洽落到 S1-09，额外增加 1 条规则（第 5 条，位于双解规则之后），并在「⑤ 版本与口径」中注明。该规则可在维护抽屉中删除。

### 3. 成本底线（替换目标毛利率）
- 大数字 = 单位总成本（USD/kg），下方小字「报价低于此数即亏损」；输入报价低于成本时该小字变红并显示差额。
- 成本结构树默认收起，展开后 5 组：① 采购成本 ② 税费（关税/反倾销/VAT 不可抵，含税率，不适用灰显）③ 加工（织造/染整/制造费用，转售形态整组「不适用」）④ 物流（可展开 6 档点选）⑤ 采购附加。
- 报价校验：< 成本 → 红底 ❌「低于成本，不可报」+ 差额/差额%；≥ 成本 → 绿底 🟢「可报，毛利 x.xxx USD/kg（x.xx%）」。
- 已删除目标毛利率、税后净利；CIT 只在脚注文字中出现，不进主数字。

### 4. 维护抽屉（⚙ 右上角）
5 个 tab：主体清单（增/删/改名/改属性）、税费参数（30 项，每项带「已核实/占位待核」标签）、判定规则（表格化四角色下拉 + 模式 + 生效开关 + 上移/下移/删除 + 新增）、数据管理（导出 JSON / 导入文件 / 导入粘贴 / 恢复默认 / 清空本地）、版本与口径。
所有改动写 `localStorage['huatex_modes_v2']`，即时反映到主界面，无需刷新。
