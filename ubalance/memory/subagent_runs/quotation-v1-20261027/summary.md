## 三、口径要点（已写入文件，勿改）

- 8 个销售模式，S1-06（买方 EPE、收货本地企业）已判定不成立并全程剔除（Excel 与 HTML 均不出现）。
- 反倾销：默认 7.8%（3.24%–12.39% 区间中值），明确标注参数可调；**未使用 17.45% 作为唯一取值**，并记录 2021 终裁、2023-11-01 期中复审、2025-10-16 日落复审时间线。
- VAT：出口/就地出口 0%，内销 8%（至 2026-12-31）；VAT 不进成本、不进利润，只影响客户到手价与现金流。
- 关税与 AD 刚性进成本；进口 VAT 可抵；FCT 不适用于 Huatex（越南卖方）。
- 96 个组合全部保留并标注适用性（成立 / 条件成立·须先补税 / 待关务确认），不删除，便于比较补税后成本。

## 五、风险与已知局限

1. **所有绝对金额都是占位值下的结果**，只能看结构与方法，不能对外报价。
2. 成本链未含：期间费用、退税资金占用（实际 2 个月一申）、汇兑损益、废品回料、信用成本。税后净利＝毛利×0.8 是简化。
3. 「保税 + 内销」按补税口径计入成本，未计滞纳金与罚款，也未体现「未补税即违法」的非财务风险。
4. 03 表固定用成品布做四档对比；纱线（关税 3%）与胚布（12%）的采购方式差异需看 01 表筛选。
5. HTML 只做了 WebKit 缩略图 + OCR 冒烟验证与几何边界校验，**未做逐像素视觉走查**（本机无 headless Chrome）。
6. 报价底线未含汇率条款与价格有效期，长周期合同须另加保护条款。
