## 三、校验机制（哪些单元格自动校验）

1. **银行流水勾稽闭环**（sheet 2，C306–C313）
   - 逐笔轧差：I 列 = 上一笔余额 + 收入 − 支出（首行起点 = T2「开户日 0 余额」锚点）
   - Σ收入（C306）/ Σ支出（C307）
   - 期末余额（C308）= I 列最后一个数
   - 差异（C310）= 期末余额 − 对账单余额
   - **校验（C311）= `ABS(差异)<1` → ✅ 勾稽闭环 / ❌ 不闭环**
   - 自检（C312）= Σ收入 − Σ支出 = 期末余额 → ✅/❌
   - 实收资本候选（C313）= COUNTIF/SUMIF Q 列「是」的笔数与金额
2. **资产负债表平衡**（sheet 5）：TOT 行 100/200/270/300/400/440 全公式；**C31 = 270 − 440**，**D31 = `IF(ABS(C31)<1,"✅ 平衡","❌ 不平衡")`**
3. **损益表层级勾稽**（sheet 6）：10 = 01−02；20 = 10−11；30 = 20+21−22−25−26；40 = 31−32；50 = 30+40；60 = 50−51−52
4. **跨表引用**：sheet 8 C4 ← `'6-重建损益表'!C16`（税前利润 50 行）
5. **税额**：CIT = `IF(应税所得<0,0,应税所得*20%)`；滞纳金 = `应纳税额*0.0003*滞纳天数`；罚款 情形② `*20%`、情形③ `*100%`（1 倍下限）；最坏 = `税+3倍罚+滞纳金`
6. **数据校验下拉 13 组**（Excel 列表长度全部 < 255）：业务性质 12 项、VAS 科目 35 项、事件类型、是否损益、待核标记、是否主张 4111 等
