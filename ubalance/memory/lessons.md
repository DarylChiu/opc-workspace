## 越南税务
1. **FCT直接法是收付实现制，不是权责发生制** (2026-06-30) — 纳税义务时点=实际支付给境外承包商时，申报期限为支付日起10天内。计提≠纳税义务产生。之前被Daryl纠正。
2. **补充协议日期在实操中可回溯** (2026-06-30) — Daryl教：文件日期可以是2025年12月31日而非2026年，文件时间线可以做到完美。不要假设文件不完美来反驳方案。
3. **PIT资本利得税率：0.1%是兜底，20%是标准** (2026-07-13) — 非上市公司股权转让，个人PIT：成本可确定→20%×净收益；成本无法确定→0.1%×转让价。上市公司→0.1%。之前把兜底税率当通用税率，被Daryl纠正。

## 2026-08-05 · openpyxl 保护工作表「整表锁死」陷阱 (误餐补贴 v0.5.2)
- **现象**: 用 openpyxl 设置 `ws.protection.sheet=True` + password 交付 v0.5.2，Daryl 打开后**所有单元格都不能点击**（含填报区）
- **根因**: openpyxl `SheetProtection` 的 `selectLockedCells` 和 `selectUnlockedCells` **默认值为 False**（官方文档签名确认）——保护开启后用户连"选中单元格"都不被允许，整表像死了一样。Excel 原生界面保护时默认勾选这两项，但 openpyxl 默认不勾 → Agent 生成的保护表必然"全锁死"
- **修复**: 必须显式设置 `ws.protection.selectLockedCells = True` 和 `ws.protection.selectUnlockedCells = True`，才能实现"能点能选、只锁编辑"
- **教训**: ①openpyxl 默认值与 Excel UI 默认值不一致，跨工具生成文件必须以目标软件行为为准做验证 ②交付锁定版前要模拟用户视角：能点、能填、锁定区有提示 ③Agent 生成 Excel 不是"设置个属性就完事"，保护相关参数必须逐项核对

## 2026-08-12 · python-docx 翻译保格式的三个坑（仓储SOP中越双语）
1. **`id(cell._tc)` 去重不可靠** — lxml 代理对象被 GC 后 id 被 Python 复用，导致后续单元格被误判「已处理」而跳过（215处预期只落了98处）。正确做法：直接遍历 `t._tbl.iter(qn('w:tc'))`，每个单元格恰好一次，无需去重
2. **`run.text` setter 会清空 `add_break()`** — 先 add_break 再 set text，break 被抹掉；必须用 `run.add_text()` 追加文本保留换行；且每行越南语前都要加 break（单行翻译也要）

4. 翻译保格式交付模板：复制原文件→逐段落/逐 tc 追加双语 run→逐项比对（段落数/样式/列宽/gridCol/合并结构/页面设置）→textutil 真实解析验证

## 2026-08-21 · 保税仓(kho ngoại quan) ≠ EPE(企业 chế xuất)
- **错误**: 编制越南税务笔试卷时，把「保税仓」直接等同于「EPE（出口加工企业）」，导致第3题框架整个用错。
- **Daryl纠错**: "保税企业=EPE企业？你确定吗？"
- **正确区分**:
  - **保税仓(kho ngoại quan/bonded warehouse)** = 海关监管下的**仓储设施**，任何企业（含普通非EPE）都可用。货物存放时暂不缴进口关税/增值税，**出仓内销时才补缴**，复出口免税。本质是"纳税时点延后"，不是身份。
  - **EPE(doanh nghiệp chế xuất)** = 一种**企业身份**，整个企业视同"非关税区(khu phi thuế quan)"，进口原料免关税+增值税、出口0% VAT、内销走"即视进出口(xuất nhập khẩu tại chỗ)"。
- **可迁移教训**: 越南海关语境下，"保税"两个字对应多个不同概念（保税仓/保税区/EPE/非关税区），不能望文生义直接画等号；做题/出题前先厘清是"仓储设施"还是"企业身份"。
- **法规锚点**: Nghị định 08/2015 + Circular 38/2015（保税仓）；Circular 219/2013 Điều 4（EPE=非关税区不征VAT）。

## 2026-08-21 · PIT住房福利判定 = 实质重于形式（不是"个人专属vs集体"）
- **错误**: 第4题我把外籍员工住宿福利的应税判定说成"个人专属=应税、集体宿舍=免税"，自己编了个不存在的区分。
- **Daryl纠错**: "是否应税的判断是根据'是否个人专属'吗？我怎么理解的不是这样的？混住+合同不写'住宿补贴'就不考虑PIT了吗？"
- **正确规则** (Circular 111/2013 Điều 11 Khoản 2 Điểm đ):
  - 雇主为员工**实际承担住房成本**（代付租金/提供住房）= 应税福利(benefit in kind)，计入PIT应税，受**15%上限**限制。
  - 判定标准 = **实质重于形式**（雇主是否实际掏钱），与"个人专属/集体"无关、与"合同/协议是否写明住宿补贴"无关。

- **可迁移教训**: 税务定性看实质不看形式，不能自己造一个法律上没有的区分（"个人专属vs集体"）；先查清法规原文的"应税/免税边界"到底划在哪条线上（这里是"自建vs租赁"），再设计判断点。

## 2026-08-22 · 出题要设"隐蔽点"（有票≠可抵）+ 保税仓账册要用数量勾稽
- **背景**: 领导对笔试卷的 3 点反馈，暴露两个出题/分析盲区。

## 2026-08-22 · 越南VAT没有"进项转出"（那是中国概念，别乱套）
- **错误**: 第2题整改时，把越南"不可抵扣进项"写成"进项转出"（进项税额转出），被 Daryl 抓："越南FDI公司哪里能进项转出啊？"

- **可迁移教训**: 跨境税务最忌讳"母语税制直译"——中国有"进项转出"、有"出口退税单证"等特有动作，越南未必有；反过来越南的"核定征收率""保税仓出仓清关"中国未必有。**写越南题目先查越南税法原文，别用中国框架去"翻译"。**

## 2026-08-22 · 越南招待费/广告费的15%上限已废止（别用旧法Circular 78/2014）
- **关键事实**: 越南 CIT 对广告费/促销费/招待费/佣金的 **15% 上限**，已被 **Circular 96/2015/TT-BTC（2015）废止**，并经新 CIT 法 67/2025/QH15 + Nghị định 320/2025 确认——现行法下这些费用**全额税前扣除**（满足一般条件：实际发生、与经营相关、合规发票、非现金支付）。
- **业务招待费 vs 员工福利**（易混，Daryl 纠过两次）:
  - 招待费（招待客户/伙伴）= 经营用途 → 进项**可抵扣** + CIT **可全额扣（无上限）**。
  - 员工福利（节日礼品/团建/免费餐，与生产经营不直接关联）= 非经营 → 进项**不可抵扣**（Circular 219/2013 Điều 14）+ CIT 不可扣。
- **广告费超额不能结转下年**（越南无"超额结转"机制，不同于中国广告费15%可无限期结转）。
- **教训**: ①越南税法的"限额/上限"规则时效性强，别拿记忆里的旧口径（Circular 78/2014）做题，先查是否已被废止 ②Daryl 要的"干扰项"设计——把易混科目（招待费/福利）并排，考考生能否区分经营用途 vs 非经营用途。
