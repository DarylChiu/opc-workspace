### 根因确认（websearch 2轮，openpyxl 官方文档）
- openpyxl `SheetProtection(sheet=False, objects=False, ..., selectLockedCells=False, selectUnlockedCells=False, ...)` — **selectLockedCells/selectUnlockedCells 默认 False**

- 修复: `ws.protection.selectLockedCells = True` + `selectUnlockedCells = True`

## 🔴 09:30+ · v0.5.2 锁版交付后用户反馈「所有单元格都不能点击」——根因与修复方案

### 事件

### 根因诊断（已定位）
- openpyxl 设置 `ws.protection` 时，`selectLockedCells` 和 `selectUnlockedCells` **默认值为 False**（openpyxl 3.1.5 WorksheetProtection 默认 `selectLockedCells=False, selectUnlockedCells=False`）。
- 保护工作表后，Excel/WPS 中「选定锁定单元格」「选定未锁定单元格」两个选项被禁用 → **用户无法点击/选中任何单元格**（连填报区都点不动），表现为整个表"锁死"。
- 即使填报区单元格设置了 `locked=False`，在 selectUnlockedCells=False 下也无法被选中。

### 修复方案（下一轮立即执行）
1. 加载 v0.5.2（或从 Daryl 回传版重新生成），设置保护时**显式开启**：
   - `ws.protection.selectLockedCells = True`
   - `ws.protection.selectUnlockedCells = True`
   - `ws.protection.sheet = True` + `password = "13226469877"`
   - 保持填报区（B4/D4/A8:B20/C8:C20/H8:H20/M8:M20）`locked=False`，公式区默认 locked
2. 两个 sheet（申请明细 + 标准与参数）都按此处理
3. 验证：重新打开确认「点击任意单元格可选中 → 填报区可编辑 → 公式区提示受保护需密码」
4. 重新交付 v0.5.2（同版号覆盖或 v0.5.3，视 Daryl 意见）
