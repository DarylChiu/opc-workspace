# 2026-10-29 日记 · 周四

## Embedding 本地化（为 10/30-31 搬回广东做准备）

**背景**：Mac mini 从越南同奈搬回广东江门，GFW 会切断 OpenRouter。原 memorySearch 走 `openai/text-embedding-3-small`（remote=openrouter），属关键路径（每 session 启动都调），不能依赖代理。

**决策**：embedding 全量切本地 GGUF，零网络依赖。经实测选型：
- `embeddinggemma-300m-qat-Q8_0`（328MB）：中文区分度差，所有结果挤在 0.37-0.44，弃用
- **`Qwen3-Embedding-0.6B-Q8_0`（639MB，1024维）：采用**。sentinel 查询 0.744 断层清晰，中文换词提问有区分度

**执行记录**：
- 模型路径 `~/.node-llama-cpp/models/hf_Qwen_Qwen3-Embedding-0.6B-GGUF_Qwen3-Embedding-0.6B-Q8_0.gguf`
- 配置：`agents.defaults.memorySearch = {provider:"local", local:{modelPath:"hf:Qwen/...",contextSize:4096}}`，已移除 `remote`(openrouter) 覆盖
- 备份：`~/.openclaw/backups/pre-cn-move/`（openclaw.json + memory md tar + baseline JSON）
- 重建耗时：1009 chunk ≈ 3分49秒；4 agent 全量约 15 分钟
- 索引维度 1536 → 1024（不同模型向量空间不兼容，必须 `memory index --force` 全量重建，不可混用）

**教训**：
1. 换 embedding 不会丢记忆——`.md` 是源数据，sqlite 只是派生索引
2. 中文记忆库选 embedding 模型，英文向小模型（gemma）不可用，必须实测断层
3. embedding 缓存（2747条）会失效，成本影响可忽略（≈$0.03）

**待办**：agent 全量重建后 → gateway 重启生效 → 搬家前剩余项（时区 UTC+7→+8、入站隧道方案、图片模型国产替代）
