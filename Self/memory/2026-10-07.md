## 【Daryl 两问 → 核条款 → 规则卡 v1.1 更正】（11:2x）
- **Daryl 两问**：①VAT 开了电子发票，是否还需在 VAT 申报表中申报？②既然开了销项 VAT，为赠送采购的原材料的 **Input VAT 能否抵扣？甚至退税？**
- **答①：必须申报。** 开票与申报是两个独立义务。开了电子发票必须在**开票所属期**计入 **01/GTGT** 销项并列入销项发票清单；无偿转移的**纳税义务时点＝交付时点**（非收款时点）→ **未收款不构成不申报理由**；电子发票已实时上传税局 → **系统自动比对，藏不住**。申报周期：月报（次月 20 日前）/ 季报（季末次月 30 日前，依 NĐ 126/2020 标准）。漏报＝补税＋滞纳金（0.03%/天）＋罚款。
- **答②：能抵，不能退。**
  · **可抵扣**：**Luật 48/2024/QH15 · Điều 14 khoản 7** 明列——用于 `cho, biếu, tặng, khuyến mại, quảng cáo` 的货物（含外购与自产），**其进项 VAT 得抵扣**。

## 【Daryl 追问】PI 的 0% 与 FOC 发票税率是否矛盾（16:0x）→ 规则卡 v1.3 + 自我修正
- **Daryl 原话**：「那是不是有点不对？Self，我们FOC出库后大部分也是发给海外客户的，需要报关出口的，其中Proforma Invoice就是0%税率的，难道我们FOC发票跟PI的税率不一样吗？这需要解释吗？」
- **核查结论（含我自己的修正）**：
  1. **PI（Proforma Invoice / hóa đơn chiếu lệ）不是税务发票、无法律效力**——多源一致：不是正式结算发票、不产生付款义务、不能作为有效凭据。所以 **PI 上的 0% 只是商业表述（出口报价不含 VAT），不决定也不证明税务处理**；决定税务的是「出口发票＋报关单＋合同＋支付凭证」。
  2. ⚠️ **自我修正：我上版写「出口 0% 走不通（缺合同＋支付凭证）」说过头了。** 准确分层：
     · **②非现金支付凭证：确定缺**（FOC 无收款，这条硬）
     · **①合同：有争议**——严格法条要「**该批出口货物**的销售/加工/委托出口合同」，原销售合同＋质量条款能否充当，**未定**
     → 所以 0% 成立与否**取决于税局认定**，属口径问题，不是我单方能下结论的。
  3. **新增 §7c「单据链一致性」（比单看税率更致命）**：FOC 出口涉及 PI / 出口发票 / 报关单 / 申报表四份文件，必须自洽。**「报关出口 ＋ 发票按 8%」比「全按 0%」更危险**——后者至少口径自洽，前者是海关与税务两套口径正面冲突。
  4. **列出发给 Huatex 的三件事实（我查不到，只在公司单据里）**：
     F1 FOC 的 PI 上写的到底是「0% 税率」还是「FOC / No Charge / 单价 0」？
     F2 FOC 实际开的是哪种税务发票（出口发票 0% / 内销 8% / 没开票）？
     F3 历史上 01/GTGT 是怎么填的（0% 出口行 / 适用税率行 / 未申报）→ 决定**已暴露面**。
     这三件一给，即可算出：当前口径是否自洽 / 已暴露面多大 / 「照旧」vs「纠正」两条路的代价。
- **对 Daryl 问题的直接回应**：「需要解释吗」的答案＝**对客户不需要，对税务机关必须有得解释，且最好主动解释**；解释的抓手是**单据链一致**，不是 PI 上的那个 0%。
