## 0. 口径说明（先锚定范围）

「FOC」在越南税务与会计语境下对应多种越南语表达，**税法待遇各不相同**：

| 中文 | 越南语 | 性质 |
|:---|:---|:---|
| 无偿赠送货物 | hàng hóa cho, biếu, tặng không thu tiền | 视同销售（VAT） |
| 促销赠品 | hàng khuyến mại | 合规促销→VAT 计税价可为 0 |
| 免费样品 | hàng mẫu | 促销形式之一 |
| 客供料件 | nguyên vật liệu do khách hàng cung cấp miễn phí | 加工/受托生产 |
| 保修免费换件 | hàng bảo hành thay thế miễn phí | 售后服务义务 |
| 接受赠予 | nhận quà biếu, tài trợ | 其他收入（TK 711） |

> ⚠️ 本稿立场：**越南境内 CIT 纳税人** 发出/取得 FOC 的税务与会计处理。**未覆盖**：海关估价技术细节、**转让定价视角下的关联方无偿交易**、FCT。
> ⚠️ 越南 2025–2026 处于法规密集修订期，**任何条款落地前须复核当期生效版本**。

| V1 | **Luật thuế GTGT 48/2024/QH15** | 2024-11-26 通过 / **2025-07-01 生效**（替代 13/2008/QH12） | 赠送与促销货物的计税基础 | 中（官方税务门户确认生效日） |
| V2 | **Nghị định 181/2025/NĐ-CP · Điều 6** | 2025-07（政府门户已发布） | **Điều 6 标题已核**：「Giá tính thuế đối với hàng hóa, dịch vụ dùng để trao đổi, tiêu dùng nội bộ, **biếu, tặng, cho** và hàng hóa, dịch vụ dùng để **khuyến mại**」；**具体款项文字待核** | 高（条文标题）／待核（款项） |
| V3 | Luật sửa đổi, bổ sung một số điều Luật thuế GTGT | **2026-01-01 生效** | 编号待核 | 低 |
| V4 | **Nghị định 81/2018/NĐ-CP**（经 **128/2024/NĐ-CP** 修订） | 现行 | 贸易促销的形式与程序 → 决定能否适用「计税价=0」 | 中 |
| V5 | **Nghị định 254/2026/NĐ-CP** | 2026-06-30 颁布 / **2026-07-01 生效**（替代 NĐ 123/2020） | 电子发票与凭证；FOC 亦须开票；可按月/季汇总开票 + 明细清单 | 中（四家软件商/中介多源一致，**非官方门户**，故不计「高」） |
| V6 | （沿革）Thông tư 219/2013/TT-BTC · Điều 7 | 2025-07-01 前适用 | 「biếu tặng 按同类/等价商品市价计税」原则来源 | 高 |

**核心口径（VAT）—— 含表述修正**
1. **合规促销**（符合 NĐ 81/2018 的促销形式，如送样、买赠）→ 依 Điều 6 NĐ 181/2025，**计税价按 0 确定**；实务中因此**不产生销项 VAT**。
   > ⚠️ 概念区分：**「计税价/税基为 0」 ≠ 「免税/不征税」**。二者在申报表填列与后续用途变更处理上不同。本稿暂按「税基为 0 → 无销项 VAT」表述，**具体款项文字未核，落地前必须回原文**。
2. **非合规促销的临时赠送**（ad-hoc gift）→ **计税价 = 赠送时点同类/等价货物市价**，**须计算销项 VAT**。
3. 「标为促销」≠ 自动享受 0 计税价；须能证明构成合规促销（内部决议、促销方案、执行证据；需备案/登记时另附备案材料；注意 NĐ 81/2018 部分促销形式**免事前备案**）。
4. **受赠方**：发票上显示的 VAT **不自动可抵扣**，须按进项抵扣条件实质判断（含无现金支付凭证要求，进口礼品等有例外）。

### 1.2 企业所得税（CIT）

| # | 法规 | 颁布 / 生效 | 关键点 | 置信度 |

| C1 | **Luật thuế TNDN 67/2025/QH15** | 2025-06-14 通过 / **2025-10-01 生效**，适用于 2025 纳税年度 | 新 CIT 法 | 高（官方公报 congbao + 税务分局面） |
| C1b | **Nghị định 320/2025/NĐ-CP** | **2025-12-15 颁布** | 67/2025/QH15 的指导议定（细则条款待逐条核）。⚠️ 颁布日晚于法律生效日（2025-10-01）属常见衔接现象，但**自 2025 纳税年度的适用衔接方式待核** | 中（多来源一致：律所/法律数据库） |

**核心口径（CIT）**
- 赠送支出：**单据齐全**（合法发票；≥2000 万 VND 须有无现金支付凭证）且与经营相关 → **可扣除**。
- **限定条件（重要）**：本结论适用于**非福利基金列支、非关联方**的常规经营性赠送。以下三类**不适用或另受约束**：
  - 由**奖励福利基金（quỹ khen thưởng phúc lợi）**列支 → **不得扣除**；
  - **关联方**之间的无偿转移 → 另受**转让定价规则**约束（本稿未覆盖）；
  - 若被认定为**广告促销性质**，须复核是否落入广告促销费的相关条件。
- ⚠️ **冲突项 1**：`taisancong.vn`（2025-03）持「不得扣除」观点，依据 Luật 32/2013 时代的限额条款 → 疑为旧口径残留，**待原文核验**。

| P2 | 新 PIT 法（编号待核）+ 253/2026 | 2026-07-01 | 受赠所得（**非任职关系**）：单次**超过 2000 万 VND** 的部分按 **10%**（旧口径 1000 万已废） | 中（MISA 单一来源转述，**待原文核**） |
| P3 | 员工实物福利 | 现行 | **因任职受雇取得的实物福利 → 工资薪金所得（累进税率 5%–35%）** | 中 |

> ⚠️ **冲突项 2（PIT 口径）**：MISA 示例把「员工节日礼品」按**受赠所得 10%** 计算（2500 万 → 500 万 × 10% = 50 万 VND）。
> 但同文又述「受赠人为员工时按工资薪金」——**同一场景两套口径并存**。
> **本稿判定倾向**：员工因任职关系取得 → 应走**工资薪金累进税率**；「受赠所得 10%」适用于**非任职关系的个人受赠**。**此为推断，待 NĐ 253/2026 原文确认，Daryl 与 Balance 决策前须复核。**

## 2. VAS 入账处理（分录框架，依 TT 99/2025 分类原则）

### 2.1 情形①：赠送外部客户（不作收入）

```
Nợ  TK 641 / 642   （存货成本 + 销项 VAT，全额计入销售/管理费用）
Có  TK 155 / 156   （存货成本）
Có  TK 3331        （销项 VAT = 同类商品市价 × 税率）
```
> 要点：**不确认收入（TK 511）**，全额进费用；销项 VAT 由赠送方承担。

### 2.2 情形②：赠送员工，且由奖励福利基金列支（需作销售）

```
Nợ  TK 353         （奖励福利基金）
Có  TK 511         （收入）
Có  TK 3331        （销项 VAT）
—— 同时结转成本 ——
Nợ  TK 632
Có  TK 155 / 156
```
> 要点：**须确认收入与成本**，不得直接进费用（最易错点）。CIT 上该支出不得扣除。

### 2.3 情形③：接受赠予一方

```
Nợ  TK 152 / 156 / 211   （按收到时点公允价值入账）
Nợ  TK 133               （满足抵扣条件时）
Có  TK 711 （thu nhập khác）  /  Có 3387（递延）
```
> 要点：按**公允价值**入账，对应「其他收入」；须留存来源证明备查。

## 5. 关键风险提示（实操）

1. **0 计税价是「合规促销」的特权，不是「赠送」的默认** —— 误用＝漏销项 VAT + 处罚。
2. **无论有无收款都必须开电子发票**（NĐ 254/2026，2026-07-01 起）—— 「不卖就不用开票」是高频误区。
3. **受赠方进项 VAT 不自动可抵** —— 收到 FOC 发票即抵扣是常见稽查点。
4. **员工福利路径走错＝双错**（少确认收入 + 违规扣除 + PIT 口径错）。
5. **PIT 起征点疑已从 1000 万升至 2000 万 VND** —— ⚠️ **单一来源（MISA）转述，尚未回 NĐ 253/2026 原文核验，不得作为确定事实使用**。
6. **关联方无偿转移**另受转让定价约束 —— 本稿未覆盖，涉关联交易须单独评估。
