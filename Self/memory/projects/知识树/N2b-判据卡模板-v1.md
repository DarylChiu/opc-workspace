## 2. 已填满的真实示例（财务域 #7 · 越南 VAT 三层分离）

> 选它做样板的原因：**这是全库唯一已有判断层的资产**（其余 148 份为资料层），可当场证明「判据卡 ≠ 定义卡」长什么样。

### 越南 VAT 三层分离 · 判据卡

**① 概念边界**（是什么 / 不是什么）
- **是**：同一笔无偿转移货物（biếu / tặng / cho / 交换 / 代薪）在越南**三个层面各自独立定性**：VAT 层计税、会计（VAS）层不确认收入、CIT 层不确认应税收入只判费用可扣除性。
- **不是**：
  - 不是「视同销售」——**越南法上不存在该制度**，「视同销售」是中国会计/税法概念，属高危概念移植词。
  - 不是「三层税率相同」——三层是三种**判定对象**，不是同一个数的三次计算。
  - 不是「会计不确认收入 ⇒ 税务也不用管」——VAT 层照样按已售商品计税。

**② 常见误判**（人会犯的 + AI 会犯的，分开写）
- **人**：据「会计没确认收入」推「税务没义务」，漏申报销项；或反向据「VAT 计税了」在账上确认收入（多计收入 + 多计 CIT 应税收入）。
- **AI**：**高频**把中文「视同销售」直译越南语并当作越南法概念使用，进而编出不存在的法条；以及把「三层分离」压成「一个税率三种算法」的算术题。

**③ 证据标准**（凭什么下这个判断；看到什么就算，看不到就不算）
- **成立需**：①能指出货物转移类型属 biếu/tặng/cho/交换/代薪之一 ②能指出 VAT 计税价取「同类或等价商品市价」而非成本 ③能分开陈述三层结论，且不把三层合并成一个数。
- **足够即止**：VAS 具体计入 641 还是 642 属科目细节，**不影响判断成立**，不必现场查证。
- **不成立**：只答出一层、或答成「视同销售」、或给出「三层之间需要互相调整」的说法。

**④ 口径来源**（A 法条 / B 官方答疑 / C 实务一致 / D 无口径 + 文号与时间）
- **级别**：**A（法条）** + 部分 B（申报口径）。
- **锚点**：
  - VAT 层：**Luật 48/2024/QH15** điểm c khoản 1 Điều 7（biếu/tặng/cho/… 须如已售商品计税，计税价＝同类或等价商品市价）
  - 进项与退税：**Luật 48/2024 Điều 14 khoản 7**（用于 cho/biếu/tặng/khuyến mại/quảng cáo 的货物进项**可抵扣**）；**Điều 13**（退税限 0% 出口且未抵进项 ≥ 3 亿 VND → 本场景**无退税资格**，且**不存在「补销项 + 进项转出」双罚**）
  - 申报行归属：**CV 90157/CT-TTHT**（B 级官方答疑）——无偿转移**不填 0% 出口行**，填适用税率行；填 0% ＝向税局主张符合条件出口，主张不成就回 8% 按市价补销项 + 滞纳金 + 罚款
  - 会计层：VAS 不确认 doanh thu，全额含销项 VAT 进 641/642

---
**附注 1 · 触发条件**：出库单上出现「FOC / 免费 / 样品 / 客诉补货 / 赠送」字样，且货物已交付。
**附注 2 · 反例**：2026-10-07 我（Self）在 FOC-VN v0.4 稿中写「按同类市价确认视同销售收入」——**越南会计根本不确认这笔收入**，Daryl 当场质疑后重写（三层分离表述）。
**附注 3 · 时效**：Luật 48/2024 自 2025-07-01 生效；**若越南 VAT 法再次修订，本卡 ④ 需重锚，重锚前整卡降为 D 级不可用**。
