## 2. 两个实证场景的关键特征（Daryl 描述 + Self 结构化）

| 维度 | **H1 开发阶段样品** | **H2 客诉免费补货** |
|:---|:---|:---|
| 触发 | 成衣厂/成鞋厂开发新季，Huatex 配合打样 | 生产失误 → 不良率高 → **QA 抽验不足** → 客诉 |
| 数量 | **5–10 码**（小额） | 按不良批次（相对大额） |
| 是否收款 | 不收 | 不收 |
| 出货方式 | 库存领用 → **国际快递 / 本地快递** | 库存出库 → **报关** |
| 报关 | **部分未报关** ⚠️ | **报关**（海外客户 / 越南 EPE 企业） |
| 对方主体 | 成衣厂 / 成鞋厂（可境内、可境外） | 海外客户 / 越南 EPE（DNCX） |
| 是否回收旧件 | 不适用 | **不回收**（运费不划算）⚠️ |
| 与订单勾稽 | **无法勾稽** ⚠️ | 当前未关联，但**数据可关联** ⚠️ |
| 时间压力 | **研发周期紧**（决定动作会被压缩） | 客诉处理压力 |
| 业务定性（**待 Daryl 确认**） | 研发/市场投入？还是促销送样？ | 质量责任赔付？还是无偿赠送？ |

> ⚠️ **「业务定性」这两个问号是整个报告的分水岭**：
> - 定性为**促销送样** → 走「计税价 = 0」路径（前提：NĐ 81/2018 登记/通知）
> - 定性为**质量责任赔付** → 走「视同销售/按同类市价计税」路径，**且可能丧失计税价 0 的适用**
> - 定性为**研发投入** → CIT 上走研发/管理费用口径，VAT 仍需处理
> 这三条路的会计科目、税负、单据要求**全部不同**。**请 Daryl 先定这个性，P2 才有落点。**

## 4. 判定闸门（OUT 线 · 不声称穷尽）

```
G1 · 收不收款？ → 两场景均不收款 → 直接进入 FOC 处理（本项目不含 G1b 中间带）

G2 · ★报关 or 不报关？（H1/H2 分水岭）
  ├─ 已报关（H2 全部 / H1 部分）→ 出境或供 EPE → 出口侧税负路径（G3-a）
  └─ 未报关（H1 部分）→ **无报关单 → 出口 0% 条件不满足** → 默认按内销（G3-b）

G3 · ★业务定性？（决定会计科目 + 税负路径 —— 本项目最关键闸门）
  ├─ 甲「研发投入」   → 费用科目偏研发/管理费用；VAT 仍需处理
  ├─ 乙「促销送样」   → 计税价 0 路径（前提：NĐ 81/2018 登记/通知）
  ├─ 丙「质量责任赔付」→ 视同销售 + 赔付凭证链（H2 大概率落此）
  └─ 丁「无偿赠送」   → 按同类/等价市价计销项
  ⚠️ 定性不定，S5/S6 全部悬空

G4 · 对方主体？
  ├─ 境内成衣厂/成鞋厂
  ├─ 境外客户（成衣厂/成鞋厂）
  ├─ **越南 EPE 企业（DNCX）** → 视同出口，手续与 0% 条件另议【待核】
  └─ 关联方 → 触发转让定价，超出本项目范围

G5 · 与订单的勾稽关系？（H1/H2 的实质差异）
  ├─ 无法勾稽（H1）→ 只能按「独立免费出货」处理
  │    → CIT 扣除依赖费用性质的说明力，风险更高
  └─ 可勾稽/数据可关联（H2）→ 有两条路：
       ├─ 作为**质量赔付/销售折让**冲减原订单（需合同/客诉证据）
       └─ 作为**独立赠送**按市价处理
       ⚠️ 两条路的收入与销项结果不同，须 Daryl 定策略
```
