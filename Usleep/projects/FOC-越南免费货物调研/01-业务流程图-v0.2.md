## 2. 判定闸门（**不声称穷尽**）

> ⚠️ v0.1 曾隐含「G 系列覆盖所有岔路」，此前提**已删除**。下表为当前已识别的岔路，未识别者在 P2 节点展开时补。

```
闸门 G1 · 收不收款？（含中间带，非二元）
  ├─ G1a 完全无偿 ……………………… 进入 FOC 主流程
  └─ G1b 部分收款（工本费 / 客户承担运费 / 保外低价换件）
       → 收款部分开票 + 计销项；未收部分按 FOC 处理
       → ⚠️ 判定时点常在报价确认/维修完成，**可能晚于 S0**

闸门 G2 · 开什么票？
  ※ 性质：**判定节点**；**执行点在 S3**（与 Phiếu xuất kho / 发货同步）；
    S4 只是单据归集与「缺什么会怎样」的后果说明。
  ├─ 收款的 ………………………… 必须开票（按销售处理）
  ├─ 在保 + 零部件/维修 ……… 不开 VAT 票，走内部单据
  ├─ 在保 + 整机换新
  │    ├─ 原票可追溯 ……… **调整发票（hóa đơn điều chỉnh）**
  │    └─ 原票不可追溯 …… 收回原票分支 / 内部单据分支（**待核**）
  ├─ 合规促销送样 ……………… 开 0 价电子发票（计税价 0）
  ├─ 非合规赠送 ……………… 按同类市价 + 销项（丧失计税价 0 特权）
  └─ 员工福利 ………………… 按福利口径开票（CIT/PIT 另议）

闸门 G3 · 跨境税负路径？
  ├─ 出口免费样品 … 默认路径＝**按内销计税**
  │    （无银行付款 → 不满足出口 0% 条件；无报关单时进项亦不得抵扣）
  │    → D3 决策点剩余问题：**是否存在例外或替代方案**（原「三路径并列」表述已收敛）
  └─ 进口免费货 … ⚠️ **两条线必须分开**：
       (i) **关税免除**：Luật 107/2016/QH13 Điều 16（quà biếu/tặng ≤200 万 VND
           或应缴税 <20 万 VND，≤4 次/年）
       (ii) **进口 VAT 免除**：另一套依据，不得与 (i) 混同
       ⚠️ NQ 174/2024/QH15 停免范围**仅限「≤100 万 VND、经快递寄送」**，
          不得泛化为「进口小额免税已停」

闸门 G4 · 对方是谁？（OUT 侧）
  ├─ 客户 ……………………… 促销口径
  ├─ **客户中奖** …………… 触发 **PIT 代扣代缴**（支付方义务）
  ├─ 员工 ……………………… 福利口径（⚠️PIT 口径未决，P2 前不得据此入账）
  ├─ **非员工自然人第三方**（KOL/中介/合作方）
  │                            → PIT + CIT 扣除双重判定
  ├─ **公益/人道受赠对象** → 影响关税免除与 CIT 扣除资格
  └─ 关联方 ………………… 触发转让定价，超出本项目范围

闸门 G5 · IN 线专属闸门（v0.2 新增）
  ├─ 境外供应商是否开票？FOC 是否开具 0 价发票？
  ├─ 进口申报价如何确定？（无偿货物完税价格认定）
  ├─ 运保费是否计入完税价格？
  └─ 客供料件是否走加工贸易/保税路径？（决定 S2.4/S2.5 是否启动）
```

## 4. P2 节点展开清单（编号表）

| 节点 | 名称 | 展开内容（固定五段式） |
|:--|:---|:---|
| S0 | 触发 | 情形枚举 + 需留痕的触发凭据 |
| S1 | 申请·审批·定性 | 单据模板 + 合规前置（**Điều 17 通知 / Điều 19 登记分列**）+ ⭐履约/无偿定性判据 |
| S2 | 订单·报关·完税·放行 | 境内 / 跨境 OUT / 跨境 IN（**含完税**）/ 加工合同与定额 / 结转报告 |
| S3 | 实物移动 | 出/入库单据 + 回收件处理 + **G2 执行点** |
| S4 | 单据归集 | 五条单据链（保修/发票/跨境/加工/备查）+ **缺失后果** |
| S5 | 会计入账 | VAS 分录（**每笔标「已核/待核」**）+ 与 TT 99/2025 科目表对照 |
| S6 | 税务 | VAT / CIT / PIT / 海关四税分述 + 减征税率与除外清单 |
| S7 | 申报 | 申报表 + 时点 + 常见漏报 + **加工结转报告** |
| S8 | 归档备查 | 台账设计（含**定额与实际耗用差异**）+ 稽查应对资料包 |

**每个节点的展开格式统一为：**
```
【触发条件】→【操作动作】→【必备单据】→【VAS 分录（带置信度）】
→【税务影响】→【风险/高频错点】→【依据（可定位 URL + 抓取时间）】
```
> 纪律：**凡未回一手原文核验的条款，一律标「待核」并进 §6.2，不得以确定语气出现在正文**（10/05 教训）。
