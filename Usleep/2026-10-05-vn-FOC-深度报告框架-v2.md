## 2. 场景 A｜保修 / 索赔免费换件

### 2.1 子场景拆解（**判定轴：有没有收款 → 在不在保 → 换件形态**）

| 代号 | 子场景 | 是否开票 | 本稿深度 |
|:--|:---|:---|:---|
| **A0** | **义务外有偿维修/换件**（保外、或保内但另收费用） | ✅ **必须开票**：确认收入 + 计销项 VAT（现行 8%） | ✅ 已展开 |
| A1 | 保内**免费维修**（不出货或只出耗材） | ❌ 不开 VAT 发票，用内部单据 | ✅ 已展开 |
| A2 | 保内**换零部件**（linh kiện, phụ tùng） | ❌ 用内部单据 | ✅ 已展开 |
| A3a | **整机换新·原票可追溯** | ✅ 退货/调整发票 + 新货发票 | ✅ 已展开 |
| A3b | **整机换新·原票不可追溯**（多层分销/个人买家未取票） | ✅ 走「收回原票/内部单据」分支 | ✅ 已展开 |
| A4 | 索赔后供应商免费补货 | 视来源而定 | ⚠️ **本稿未展开（G6）** |
| A5 | 出口产品用进口零配件保修 / 临时出口维修后复进口 | 海关单据 | ⚠️ **本稿未展开（G2）** |

> 📌 **判定分界（回答「什么情况下必须开票」）**
> - **收了钱** → 一律开票、确认收入、计销项（**A0**）
> - **没收钱且在保** → 不开 VAT 发票；但**整机换新**因构成「退货+新售」两笔流转，仍须开票（**A3a/A3b**）
> - **关键判据不止「零件 vs 整机」，还有「原销售发票能否追溯」**（决定退货票由谁开）

### 2.3 VAS 分录

**A0 — 义务外有偿维修/换件（新补）**
```
① 收到维修/换件款（开票价含 8% VAT）
   Nợ TK 111/112/131
   Có TK 511          （维修/换件收入）
   Có TK 3331         （销项 VAT = 不含税价 × 8%）
② 结转材料/人工
   Nợ TK 632 / Có TK 152, 155, 156（材料）
   Nợ TK 154 / Có TK 334, 622...（人工，按制度归集）
```
> ⚠️ **这是"必须开票"的场景**：只要收款（含保外、含保内但另行收费），一律开票、计销项、确认收入。

**A1/A2 — 保内免费（不开 VAT 发票）**
```
① 期末计提准备金（会计口径）
   Nợ TK 641 / Có TK 352
② 实际发生（领用零部件）
   Nợ TK 352                     （冲减准备金；未提准备金的直接进 641）
   Có TK 152 / 153 / 156         （零部件成本）
   —— 人工/外购服务：Nợ TK 352 / Có TK 334, 331, 111...
   ⚠️ 此处通常**不再出现 TK 133**：零部件在**采购环节**已抵进项（Nợ 152 + Nợ 133 / Có 331）；
      仅当企业**按含税成本入库、采购时未抵扣**时，才在此处补挂 133。
```
> ⚠️ CIT：只有**按财政部指引提取**的准备金可税前扣除；期末多提须**冲回**；未用完的预提不可扣除。

**A3a — 整机换新·原票可追溯**
```
机制：「退货 + 新售」两笔独立流转 → 开两次票（依 TT 91/2026 Điều 10 khoản 5 điểm c）
① 处置原销售（调整/退货发票）
   借 〔销售退回类科目〕
   借 〔销项 VAT，冲减〕
   贷 〔应收/客户往来〕
   冲回成本：借 〔库存商品〕/ 贷 〔主营业务成本〕
② 发出替换机（新货发票，**金额＝原售价以对冲**，故客户无付款义务）
   借 〔主营业务成本〕/ 贷 〔库存商品〕
   借 〔应收/客户往来〕/ 贷 〔主营业务收入〕、〔销项 VAT〕
③ 申报归属：**按 TT 91/2026 确定开票主体与时点**，两笔在**同一申报期**内对冲（≠「下一期」）
```
**A3b — 整机换新·原票不可追溯**
```
走「收回原票 / 内部单据」分支：由本方收回原发票（或个人买家未取票）后开具调整发票；
若原票确实收不回 → 改用内部单据 + 保内证明作为 CIT 扣除凭证，**不按退货开票路径走**。
⚠️ 该分支存在性来自公函转引（gonnapass），**原文未下载，分支细节待 G1 核**。
```
> ⚠️ 具体科目号（`hàng bán bị trả lại` 类科目在 TT 99/2025 下的编号与名称）**待回科目表核对**——本稿不写猜的科目号（这是 G1 之外的**已知落地缺口**）。

### 2.4 单据清单

| # | 单据 | 用于 | 必要性 |
|:--|:---|:---|:---|
| 1 | `Phiếu bảo hành`（含 4 要素：受保人名址 / 对应发票号·字轨·开票日 / 受保商品） | A1–A3 | **必须** |
| 2 | `Biên bản kiểm tra sản phẩm`（保修站出具） | A1–A3 | **必须**（CIT 扣除） |
| 3 | `Phiếu xuất kho linh kiện, phụ tùng thay thế` | A2 | **必须** |
| 4 | `Phiếu nhập kho`（收回故障件） | A3 | **必须** |
| 5 | 销售合同/发票（证明保修义务与条件） | A1–A3 | **必须** |
| 6 | 调整发票 + 新货发票（或收回原票的留痕） | A3a/A3b | **必须** |
| 7 | 报关单 + 免税依据 | A5 | **必须** |

### 2.5 风险点
1. **把 A3 整机换新当成 A2 处理（不开票）** → 漏销项 + 发票违规，最大的洞。
2. **A0 义务外有偿维修未开票/未计收入** → 漏销项 + 漏 CIT 收入。
3. **`Phiếu bảo hành` 要素不全** → CIT 扣除被否。
4. **保修准备金列错科目（用 335）或提取不合规** → 税前不得扣除。
5. **A3 按「同价对冲」时新票金额口径未定义** → 易虚增收入与销项。
6. **税率仍按 10% 计** → ⚠️ **2026-12-31 前现行标准税率为 8%**（NQ 204/2025 + NĐ 174/2025），算错 2 个点。

### 3.3 VAS 分录

**B1 境内送样（合规促销）**
```
   Nợ TK 641 / 642        （样品成本，全额进销售/管理费用）
   Có TK 155 / 156        （存货成本）
   —— 销项 VAT = 0（计税价为 0）→ 无 3331
   —— 进项：已抵不转出（**条件见下方 📎，置信度：中**）
```
> ⚠️ **不开 VAT 发票 ≠ 不开票**：须开**电子发票**，价 0，注明样品/促销性质。
> ⚠️ **合规三件套**：①依 NĐ 81/2018 **Điều 17 登记/通知**（或属免登记情形）②促销方案 ③执行证据。三者缺一 → 计税价不为 0，**降级为「赠送」→ 按同类市价 + 8% 计销项**。
> 📎 **「进项可抵」的落点与限度**（置信度：中）：现行锚点应在 **Luật thuế GTGT 48/2024/QH15 的进项抵扣条款**（非已失效的 TT 219/2013）。**中间步骤**：计税价 = 0 属「视同销售的计税价规则」，**不自动等于进项可抵**；实务认定进项可抵的落点是「该批货物用于促销属生产经营用途」。故两点**联动**：促销不合规 → 既补销项，进项亦可能被要求转出。

**B4 接受送样方**
```
   Nợ TK 152 / 156 / 211  （按收到时点公允价值）
   Có TK 711 （thu nhập khác）
```

### 3.4 风险点（样品）
1. **「送样不用开票」是错的**（NĐ 254/2026 + TT 91/2026）→ 必须开 0 价电子发票。
2. **缺登记/通知或促销证据** → 计税价 0 被否 → 按同类市价 + 8% 补销项。
3. **样品给了员工** → 从「促销」变「员工福利」→ 换一套规则（工资薪金；福利基金列支不得扣除）。
4. **进口样品以为不用报关** → 未申报的免税货物 = 走私风险。
5. ⚠️ **B2 时效坑**：≤100 万 VND 小额进口 VAT 免税**已于 2025-01-14 停止**（NQ 174/2024/QH15）——仍按旧规操作会漏缴。

## 4. 关键分歧（不站队）

### 分歧：**出口免费样品能否适用 0% VAT？**

| 立场 | 来源（权威等级） | 推理 | 后果 |
|:---|:---|:---|:---|
| **立场甲** 不适用 0%，按内销计税 | aps-audit.vn（审计事务所博客·实操向） | 出口 0% 须有银行支付凭证；无偿样品不可能有收款 → 不满足条件 → 按内销计税 | 多缴 8%（减征期内） |
